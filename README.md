# Job Bot

Job Bot — приложение для отслеживания и управления большим потоком вакансий, которое может почти полностью автоматизировать процесс отклика. Степень автоматизации настраивается: от простого списка вакансий до поиска и откликов без участия человека.

[**Скачать для Windows**](https://github.com/DeadEye2501/job_bot/releases/latest/download/JobBot.exe) · [**Скачать для macOS (Apple Silicon)**](https://github.com/DeadEye2501/job_bot/releases/latest/download/JobBot-macos.zip)

---

## Зачем

- ⏱ **Время.** Поиск, чтение вакансий и отклики приложение выполняет само. За человеком — проверка результата и собеседования.
- 📡 **Охват.** Все заведённые источники опрашиваются с заданным в настройках интервалом, пока включён автоматический режим.
- 📒 **Учёт.** Гибкая система статусов, позволяющая понять, на каком этапе находится та или иная вакансия.

## Возможности

- 🔎 **Источники.** Вакансии берутся из Telegram-каналов, с агрегаторов и сайтов компаний, а также могут быть добавлены вручную.
- 🧹 **Отсев.** Вакансии проходят несколько этапов проверки, после которых остаются самые подходящие. Учитывается множество факторов — зарплатные ожидания, грейд, формат работы, навыки, — а дополнительные предпочтения можно указать в свободной форме.
- 🎯 **Оценка.** Каждая вакансия получает балл совпадения навыков с анкетой, и бот откликается только на те, что набрали порог. Вакансии, добавленные вручную, порог не проходят.
- ✉️ **Отклики.** Бот откликается тем способом, который допускает вакансия, — в Telegram, на сайте или письмом, — а если один не сработал, пробует следующий.
- 📝 **Письма.** Сопроводительное письмо можно написать заранее или поручить модели: тогда оно пишется под конкретную вакансию и сверяется с анкетой.
- 💬 **Переписка.** Переписка с HR в Telegram видна прямо в приложении, и если ответ говорит о новом этапе, статус вакансии меняется сам.
- 🗂 **Профили.** Для разных направлений поиска можно завести отдельные профили со своей анкетой и резюме.
- 📊 **Статистика.** Приложение показывает подробную статистику поиска: воронку откликов, распределение вакансий по статусам, конверсию каждого источника, востребованные навыки и активность HR по дням недели.
- ✅ **Режимы отклика.** Бот может откликаться полностью сам или с подтверждением: во втором случае перед каждой отправкой он показывает отклик и ждёт решения пользователя, а текст можно поправить.
- 🔒 **Приватность.** У приложения нет своего сервера и нет телеметрии: данные не уходят ни разработчику, ни третьим лицам. Всё хранится локально, пароли, ключи и сессия Telegram зашифрованы. Наружу уходит только то, без чего не обойтись: отклики — работодателям, тексты вакансий, резюме и переписка с HR — выбранной языковой модели. Для полной приватности подойдёт локальная модель в LM Studio или Ollama, но работа с сайтами с ней недоступна.

## Как это работает

| Шаг | Что происходит |
|---|---|
| **1. Находит** | Опрашивает каналы, обходит сайты, ищет по сети. |
| **2. Разбирает** | Языковая модель читает объявление и раскладывает его по полям: должность, грейд, стек, формат, зарплата, контакты. Самопрезентации соискателей отбрасываются. |
| **3. Сверяет с анкетой** | Отсеивает по грейду, формату, зарплате и запретам, оценивает совпадение навыков. |
| **4. Откликается** | Выбирает способ отклика, готовит письмо, отвечает на вопросы формы по анкете и отправляет — сам или после подтверждения. |
| **5. Следит за ответами** | Читает ответы HR, обновляет статус вакансии и показывает непрочитанное. |

## Статусы вакансий

| Статус | Значение | Куда переходит сам |
|---|---|---|
| ⚪ New | Подходящая вакансия, по которой ещё ничего не сделано. | 🔵 Applied |
| 🔵 Applied | Отправлен первый отклик, ответа пока нет. | 🩵 Answered, 🟢 Invitation, 🟢 Test, 🟣 Offer, 🔴 Decline, 🟡 Ghosting |
| 🩵 Answered | HR ответил без приглашения и тестового — первичный ответ, знакомство. | 🟢 Invitation, 🟢 Test, 🟣 Offer, 🔴 Decline |
| 🟢 Invitation | Приглашение на интервью. | 🟢 In Progress, 🟣 Offer, 🔴 Decline |
| 🟢 Test | Дали тестовое задание, ход за кандидатом. | 🟢 In Progress, 🟣 Offer, 🔴 Decline |
| 🟢 In Progress | Ожидание фидбека работодателя по собеседованию или тестовому. | 🟢 Invitation, 🟢 Test, 🟣 Offer, 🔴 Decline, 🟡 Ghosting |
| 🟡 Ghosting | Работодатель не отвечает, хотя ход за ним. Ставится сам после 14 дней молчания. | 🩵 Answered, 🟢 Invitation, 🟢 Test, 🟣 Offer, 🔴 Decline |
| 🟣 Offer | Оффер. | — |
| 🔴 Decline | Отказ работодателя по любым причинам или без них. | — |
| ⚫ Not Fit | Вакансия не подходит по тем или иным причинам: её отсеял бот или отклонили вручную. | — |
| 🟠 Scam | Скам: неоплачиваемое тестовое размером с проект, попытка заставить установить вредоносную программу под видом тестового и т. п. Ставится вручную. | — |

## Что понадобится

| Что | Зачем |
|---|---|
| Аккаунт Telegram и его `api_id` / `api_hash` | Читать каналы и писать HR от имени пользователя. Как получить ключи — ниже. |
| Языковая модель | Разбирать вакансии, писать письма, классифицировать ответы. Подойдёт локальная (LM Studio, Ollama), любая по OpenAI-совместимому API (OpenAI, OpenRouter и другие), Claude по ключу Anthropic или Claude Code по подписке. |
| Модель эмбеддингов | Узнавать повторы одной вакансии. С сервера модели или файлом с диска (см. ниже). В мастере этот шаг называется «Сравнение». |
| [Claude Code](https://claude.com/claude-code) и браузер на Chromium | Работа с сайтами: поиск вакансий на них и по сети, отклики через сайт, заполнение резюме. Claude Code должен быть выбран моделью для чата. Подойдут Chrome, Edge, Opera, Brave, Vivaldi или Яндекс.Браузер. |
| Почта и её пароль приложения | Откликаться письмами с резюме во вложении. Как получить пароль — ниже. |

<details>
<summary><b>Как получить <code>api_id</code> и <code>api_hash</code></b></summary>

Это пара идентификатор/ключ, которую Telegram выдаёт каждому приложению: с ней бот заходит в Telegram как обычный клиент.

1. Открыть [my.telegram.org/auth](https://my.telegram.org/auth) и войти по номеру телефона.
2. Перейти в **API development tools**.
3. Заполнить **App title** и **Short name** — значения любые.
4. Скопировать **App api_id** и **App api_hash** в мастер или в настройки.

</details>

<details>
<summary><b>Как получить пароль приложения для почты</b></summary>

Это отдельный пароль, который почта выдаёт программам, отправляющим письма от имени владельца ящика. Обычный пароль от ящика не подойдёт: почта не пускает с ним сторонние программы.

**Gmail**

1. Открыть [myaccount.google.com/security](https://myaccount.google.com/security) → «Безопасность».
2. Включить двухэтапную аутентификацию, если она выключена: без неё паролей приложений нет.
3. Открыть «Пароли приложений» — там же или поиском по настройкам аккаунта.
4. Вписать название, например «Job Bot», и нажать «Создать».
5. Google покажет 16-значный пароль. Его нужно скопировать сразу: второй раз он не покажется.

**Яндекс**

1. Открыть [id.yandex.ru/security](https://id.yandex.ru/security) → «Безопасность».
2. В разделе «Пароли приложений» выбрать «Почта».
3. Вписать название, например «Job Bot», и нажать «Создать».
4. Яндекс покажет пароль. Его нужно скопировать сразу: второй раз он не покажется.
5. В настройках Яндекс Почты открыть «Почтовые программы» и разрешить вход по паролям приложений: без этого почта его не примет.

**Mail.ru**

1. Открыть [account.mail.ru](https://account.mail.ru) → «Безопасность».
2. Найти «Пароли для внешних приложений» и нажать «Добавить».
3. Вписать название, например «Job Bot», и нажать «Продолжить».
4. Mail.ru покажет пароль. Его нужно скопировать сразу: второй раз он не покажется.

</details>

> [!TIP]
> Для эмбеддингов подойдёт файл модели [bge-m3](https://huggingface.co/ggml-org/bge-m3-Q8_0-GGUF/resolve/main/bge-m3-q8_0.gguf) (около 600 МБ). Его достаточно скачать в любую папку, а в мастере (шаг «Сравнение») или в настройках выбрать источник «Файл» и указать путь к нему. Сервер для этого не нужен.

> [!NOTE]
> Агент, который работает с сайтами, — это Claude Code, и работает он, только если Claude Code выбран моделью для чата. С любой другой моделью для чата сайты недоступны.

## Риски

> [!CAUTION]
> **Автоматизация действует от имени пользователя и под его аккаунтами — со всеми последствиями.**
>
> - **Telegram может ограничить или заблокировать аккаунт.** Бот работает через API Telegram и пишет людям, которые раньше с пользователем не переписывались. Telegram может счесть это спамом или нарушением своих правил.
> - **Не все сайты разрешают автоматизацию.** Правила многих агрегаторов запрещают ботов и автоматические отклики. Сайт может заблокировать аккаунт или ограничить доступ.
> - **Языковая модель ошибается.** Она может неверно оценить вакансию, ответить на вопрос формы не так или написать неточное письмо. В режиме «Автоотклик» такие отклики уходят без проверки.
> - **Почтовый ящик может попасть под ограничения** почтового сервиса при большом количестве писем.
>
> Приложение поставляется «как есть», без каких-либо гарантий. Автор не несёт ответственности за блокировку аккаунтов, утрату доступа к ним, отправленные отклики и любые другие последствия использования. Всё, что приложение делает от имени пользователя, пользователь делает на свой риск.

## Установка

**Windows.** [Скачать `JobBot.exe`](https://github.com/DeadEye2501/job_bot/releases/latest/download/JobBot.exe), положить в любую папку и запустить. Установка не нужна, первый запуск занимает несколько секунд.

> [!NOTE]
> Файл не подписан, поэтому Windows SmartScreen может предупредить о неизвестном издателе. Запустить можно через «Подробнее → Выполнить в любом случае». Папка с файлом должна быть доступна для записи (например, не `Program Files`): обновление кладёт новую версию рядом.

**macOS (Apple Silicon).** [Скачать `JobBot-macos.zip`](https://github.com/DeadEye2501/job_bot/releases/latest/download/JobBot-macos.zip), распаковать и перенести `JobBot.app` в «Программы». Маки на Intel не поддерживаются.

> [!IMPORTANT]
> Приложение не подписано Apple, и при первом запуске macOS его не пустит. Открыть его можно правым кликом → «Открыть» (на новых macOS — «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»). Запускать нужно из «Программ», а не из «Загрузок», иначе приложение не сможет обновиться.

Обновление встроено: если при запуске или после прогона найдена новая версия, значок обновления в нижней полосе окна подсвечивается, нажатие на него ставит новую версию.

## Первая настройка

**1. Мастер первого запуска.** Проведёт через вход в Telegram, выбор модели для чата и эмбеддингов и загрузку резюме (PDF, DOCX, Markdown или txt). Если дать модели разобрать резюме, она сама заполнит большую часть анкеты.

**2. Анкета.** Вкладки профиля: `CV`, `Letters`, `Skills`, `Experience`, `Projects`. По анкете бот оценивает вакансии, пишет письма и отвечает на вопросы форм — чем она точнее, тем точнее отклики. После разбора резюме её стоит проверить, особенно уровни навыков во вкладке `Skills`: их модель оценивает приблизительно.

> [!TIP]
> В `CV` предпочтения задаются строками. **Запрет** отсеивает вакансию («не рассматриваю офис»), **пожелание** учитывается агентом при откликах на сайтах, но не отсеивает, **сведения** — факты о кандидате («могу работать из ЕС»). Во вкладке `Letters` пишутся свои сопроводительные письма — тогда отклики уходят с ними.

**3. Источники.** В разделе «Контакты»:

- `Каналы` → «Добавить канал»: `@username` или ссылка `t.me/...`;
- `Агрегаторы` → «Добавить агрегатор»: адрес сайта. Затем значок входа в карточке сайта — откроется браузер, в нём нужно войти на сайт и закрыть окно. Бот подтянет резюме с сайта; в карточке нужно выбрать резюме для откликов и включить агрегатор переключателем;
- «Поиск по сети» уже есть в списке, его нужно только включить переключателем.

> [!IMPORTANT]
> На добавленные каналы нужно подписаться под тем Telegram-аккаунтом, который подключён к боту, — иначе он не увидит сообщения.

**4. Режим откликов.** В «Система → Настройки», раздел пайплайна:

| Положение | Что делает бот |
|---|---|
| Только поиск | Находит и оценивает, но не откликается. |
| Отклик с подтверждением | Перед каждой отправкой показывает, что уйдёт, и ждёт решения. |
| Автоотклик | Откликается сам. |

Там же — порог отсева и частота опроса. Для откликов письмами заполняется раздел «Почта».

**5. Автоматический режим.** Переключатель режима в нижней полосе окна задаёт только то, что бот делает сам, по расписанию:

- `Full` — опрашивает источники, откликается и разбирает ответы HR;
- `DM Only` — только разбирает ответы HR;
- `Off` — сам ничего не делает и не принимает ответы HR: пропущенное догоняется при включении.

На ручную работу режим не влияет: запуск обхода кнопкой рядом, отклик на вакансию, смена статуса и всё остальное, что нажато в окне, работает и в `Off`.

**6. Результат.** Найденное — в «Вакансиях»: статус, балл, стек, контакты, история. Ответы HR — в «Контакты → HR». Итоги — на экране «Статистика».

## Подводные камни

> [!WARNING]
> **По умолчанию стоит «Автоотклик».** Включённый `Full` сразу начнёт отправлять отклики сам. Для начала удобнее «Отклик с подтверждением»: видно, что бот отправляет.

> [!WARNING]
> **Бот пишет HR от аккаунта Telegram пользователя.** Отклики и письма вдогон выглядят как написанные им самим.

> [!IMPORTANT]
> **Для почты нужен пароль приложения, а не обычный пароль.** Его создают в настройках безопасности почтового сервиса, инструкция — в разделе «Что понадобится». Gmail, Яндекс, Mail.ru и Outlook бот узнаёт по адресу, для другой почты вписываются SMTP-сервер и порт.

> [!NOTE]
> **Пока не горят все лампы, бот не запустится.** Лампы слева в нижней полосе — база, Telegram, модель для чата и эмбеддинги. Что именно недоступно, говорит подсказка у кнопки запуска.

> [!NOTE]
> **Капчу и вход на сайт агент не проходит сам.** Когда ему нужна помощь человека, об этом говорит нижняя полоса, и агент ждёт до часа.

## Данные

Всё хранится локально:

- **Windows** — `%APPDATA%\JobBot\`
- **macOS** — `~/Library/Application Support/JobBot/`

Пароли, ключи API и сессия Telegram зашифрованы, ключ шифрования лежит в системной связке ключей. Кнопка «Удалить все данные» в опасной зоне настроек стирает всё, включая ключ.

Передаются данные в Telegram, на сайты, на почту и выбранной языковой модели.
