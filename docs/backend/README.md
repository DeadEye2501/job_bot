## Как работать

**Единица работы — заход, а не находка.** Заход берёт несколько находок по
одному предмету, правит их подряд одним диффом, и только потом зовёт ревью —
один раз на весь заход. Разбивка по заходам — в начале каждого этапа.

**Почему так, а не по находке.** Обвязка вокруг правки — три рецензента с
заданиями, их отчёты, пересборка карт, разбор находок ревью, коммит — стоит
примерно одинаково при любом размере диффа. На одиннадцати слайсах этапа 1 она
съела больше, чем сама работа: правки были по десять–сорок строк, а обвязка на
каждую — своя. Заход из пяти находок платит эту цену один раз вместо пяти.

**Что остаётся неизменным внутри захода:** тест до кода и красным там, где
меняется поведение; правило 15 — красная проверка не переносится на потом.
Пересборка карт — один раз перед ревью, а не после каждой находки.

Порядок: правки захода → пересборка карт → ревью тремя агентами (поломки,
манифест, повторы; четвёртый по тестам, если заход их писал) → правки по
находкам → коммит. Задание рецензенту собирается по
`superpowers:requesting-code-review`, иначе хук отклонит запуск.

**Признак, что заход собран верно:** его дифф читается одним рецензентом без
переключения предмета. Если в заходе три несвязанных модуля — это не заход, а
три слайса, склеенных ради счёта.

**Мутаций между слайсами нет ни у кого** — ни у тебя, ни у агента. Весь спрос по
ним в этапе 7.
