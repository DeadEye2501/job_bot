# Агрегаторы — окно

Всё, что человек видит и нажимает в работе по агрегаторам: вкладка, нижняя
полоса, карточка, анкета, настройки, статистика. Опирается на мост из трёх
планов: `docs/plans/09.10.2026 Агрегаторы — данные.md`, `… — промпты.md`,
`… — поток.md`. Они делаются без человека, окно — с ним.

## Как делается

- Вживую с человеком, экран за экраном: собрать → показать → правки до
  одобрения → ревью → коммит. Раскладку утверждает человек.
- Каждый экран — с настоящим мостом, без заглушек.
- Тексты — на «вы», без транслита.
- Зов моста пишется литералом (`call('aggregators.list')`): шов имён
  (`tests/client/test_page_contract.py`) видит только литералы. Шов прогоняется
  после всех экранов.
- Фронт — Svelte 5, тесты — vitest: `npm test --prefix client/web`. Карты —
  `front_map.py`.

## Общее «идёт обход»

**Расхождение с кодом.** «Занято» сейчас знает только нижняя полоса. Заводится
общее состояние `client/web/state/round.js`, и полоса переходит на него: учёт
один.

- [ ] `round.js` — «идёт прогон» по вестям `ingestion_started` /
  `ingestion_finished` и ожидание человека по `human_needed` /
  `human_resolved`. Единственный слушатель этих вестей. Чистые функции и
  хранилище по образцу соседних `state/*.js`; слушатель подключается в
  `Shell.svelte`, как `action_finished`.
- [x] Нижняя полоса (`client/web/app/BottomBar.svelte`) больше не ведёт `running`
  и `crawling` сама, а берёт их из `round.js`; её слушатели
  `ingestion_started` / `ingestion_finished` уходят. Сброс подписи хода при
  начале прогона (`started()` без двух флагов) остаётся в полосе и зовётся
  `$effect` по переходу `running` в правду. Имеющиеся тесты её занятости
  (`client/web/tests/`, grep по `ingestion_started`) — сторож перевода,
  зелёные до и после.
- [ ] Пока идёт обход, кнопки действий, которые запускают конвейер или агента,
  неактивны и показывают «идёт обход»: отклик агентом, «Войти», вставка
  объявления, «Прогнать заново», «Прогнать сейчас», удаление агрегатора. Всё
  остальное работает как обычно.

## Нижняя полоса

- [ ] Ход новыми ступенями `aggregator` и `apply` (`client/web/state/progress.js`)
  ложится в ту же полосу, что `channel`, и подписывается `channelPart`: подпись
  как пришла плюс счёт в скобках тем же видом `${label} (${c}/${t})` —
  «hh.ru — найдено (3/10)». Своей формулы счёта у новых ступеней нет; разводка
  ступеней — в `moved()`.
- [ ] Ожидание человека — по центру, вместо хода обхода: надпись и кнопка
  «Готово» (`system.human_done`). Ничего в окне не перекрывается. Надписи:
  `captcha` — «Требуется ввести капчу»; `login` — `Требуется войти на ${host}`.
- [ ] Весть `round_note` показывается в полосе.

`"channel" | "aggregator" | "none"` (план потока, задача 19). До правки окна у
строк агрегаторов `id` пустой, как у «Без канала».

  `${row.kind}:${row.id ?? row.aggregator_id ?? ''}`.

  именем; у канала и агрегатора с одним номером ключи разные.
