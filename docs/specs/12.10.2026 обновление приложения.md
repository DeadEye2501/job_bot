# Обновление приложения из релизов GitHub

## Цель

Собранный `JobBot.exe` сам узнаёт, что на GitHub вышла новая версия, и по
нажатию обновляется: скачивает её, заменяет себя и перезапускается.

## Версия

- Номер версии живёт одной константой в коде, вида `1.0.0`. Это единственный
  источник: тег релиза на GitHub повторяет его, а не наоборот.
- Показывается номер с приставкой: `v1.0.0`.
- Первая версия — `1.0.0`.

## Релизы

- Репозиторий публичный: `DeadEye2501/job_bot`. Ни проверке, ни скачиванию
  токен не нужен.
- Релиз — тег `vX.Y.Z` с приложенным `JobBot.exe`.
- Выпуск релиза: поднять номер в коде, собрать exe, выложить релиз с этим
  тегом и файлом. Делается по слову человека. На машине нужен GitHub CLI
  (`gh`) с входом в аккаунт; сейчас он не установлен.
- Первый релиз `v1.0.0` выкладывается из сборки, в которой уже есть константа
  версии и сама проверка обновлений: exe без них обновляться не умеет.

## Проверка

- Адрес захардкожен:
  `https://api.github.com/repos/DeadEye2501/job_bot/releases/latest`.
  Из ответа берутся тег свежего релиза, прямая ссылка на `JobBot.exe`, его
  размер и контрольная сумма.
- Новее — когда номер из тега больше своего (сравнение по числам, не строкой).
- Проверка идёт:
  - при запуске приложения, не задерживая открытие окна; неудача здесь
    молчит — человек ни о чём не просил;
  - по нажатию значка; ответ говорится плашкой.
- Периодической проверки нет.
- Проверка места прогона не занимает: её можно нажать и во время прогона.

## Значок в нижней полосе

Место — правый блок нижней полосы, левее переключателя режима. Значок —
круглые стрелки. Он всегда на месте и меняет смысл по состоянию:

| состояние | вид | подсказка | нажатие |
|---|---|---|---|
| обновления нет или ещё не проверяли | светло-серый, неяркий, но живой: реагирует на наведение | «Проверить обновления» | проверка |
| найдена новая версия | акцентный цвет | «Обновить приложение» | обновление |
| найдена новая версия, идёт прогон | неактивен | — | — |

Ответы ручной проверки — плашкой внизу цветом сообщения, не ошибки:

- новой версии нет: «Установлена последняя версия, v1.0.0»;
- GitHub не ответил: сообщение об этом тем же цветом.

## Номер версии в боковом меню

- Между распоркой и стрелкой «Свернуть/Развернуть меню», мелким серым
  шрифтом.
- Стоит в колонке значков меню шириной `--rail-w`, по её центру: в свёрнутом
  меню по центру узкой полосы, в развёрнутом — прилеплен к левому краю под
  столбиком значков и при развороте не сдвигается.

## Скачивание

- Начинается нажатием акцентного значка; во время прогона нажать нельзя.
- Скачивание занимает место прогона (`backend/bot/slot.py`). Отсюда, без
  новых флагов:
  - прогон не начать ни автоматически, ни вручную;
  - всё, что окно запирает во время прогона, заперто и теперь;
  - кнопка запуска становится «Стоп», и её нажатие отменяет скачивание.
- Ход — в существующей полосе прогресса нижней полосы: верхняя полоса со
  счётом, подпись вида «Обновление — 12 из 94 МБ». Отдельной стадией в ходе
  прогона (`update`), как у агрегатора.
- Файл ложится рядом с exe под временным именем.
- После скачивания сверяются размер и контрольная сумма с теми, что отдал
  GitHub. Не сошлось, связь оборвалась, отменили — скачанное удаляется,
  приложение продолжает работать как было, причина говорится плашкой.

## Подмена

Работающий exe не трогается. После удачного скачивания:

1. Приложение копирует свой exe во временную папку и запускает копию в режиме
   обновления (флаг `--update`), передав ей свой номер процесса, путь к
   своему exe и путь к скачанному файлу.
2. Приложение закрывается штатно, как по крестику.
3. Копия в режиме обновления не открывает окна, не берёт замка единственной
   копии и не трогает базу. Она ждёт выхода основного процесса, заменяет его
   exe скачанным файлом, запускает новый exe и выходит.
4. Новый exe при старте удаляет оставшееся от обновления — временную копию и
   скачанный файл, если они ещё лежат. Занятое (копия ещё не вышла) остаётся
   до следующего запуска.

## Запуск из исходников

При запуске через `main.py`, а не собранным exe, значка обновления нет:
подменять нечего. Номер версии в боковом меню показывается.

## Чего нет

- Периодической проверки.
- Отката на прошлую версию.
- Токена и приватных репозиториев.
- Отдельной программы-обновлялки: обновляет копия того же exe.
