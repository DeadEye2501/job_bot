# Клиент: верхнеуровневый план

Мост и фронт — то, что план бэкенда (`docs/backend/README.md`) отдельной строкой
вывел за свои границы. Здесь только состав этапов, названный человеком
13 августа 2026. Содержания у этапов пока нет: оно собирается исследованием,
которое стоит первым.

**Образец назван человеком:** соседний проект `personal_rating`. Его устройство —
мост, фронт и способ их тестировать — разобрано в
[personal-rating.md](personal-rating.md).

## Границы

**Своё:** `client/`.

**Не наше:** `backend/`, `adapters/`, `main.py`, `alembic/` — их ведёт
`docs/backend/`. Открытым там остаётся один этап 5, мутационный проход.

**Решено человеком 13 августа 2026: фронт переписывается по образу
`personal_rating`,** а не переводится на новый канал как есть. Это значит Svelte
и Vite, пять слоёв (`api`, `app`, `components`, `state`, `styles`), палитра одним
файлом и раздел `front` в `.claude/clean.json`. Довод: заменить один канал можно
и в монолитном `main.html`, но тестируемость фронта от этого не появится —
проверять нечего, пока логика сидит в разметке. Разбор образца —
[personal-rating.md](personal-rating.md).

## Что известно до исследования

- **Три широких немых `except`** живут в `client/` — числом их назвал итоговый
  замер бэкенда, местами не назвал никто;
- **фронтовые проверки скилла в этом проекте выключены:** в `.claude/clean.json`
  нет раздела `front`, поэтому ни границы слоёв, ни цвет мимо палитры, ни повтор
  блока CSS не проверяет ничто. Раздел объявляется по итогам исследования — имена
  слоёв берутся из раскладки, а её ещё нет;
- **`client/web/qwebchannel.js` привезён вместе с Qt** — переход на pywebview
  задевает не только фронт.
