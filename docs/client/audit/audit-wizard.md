# Сверка мастера первого запуска: `wizard.html` → Svelte

Образец: `scratchpad/old/wizard.html` (1225 строк).
Новое: `client/web/app/WizardScreen.svelte`, `WizardTelegram.svelte`, `WizardLlm.svelte`,
`WizardCv.svelte`, `components/WizardSteps.svelte`, `components/WizardFoot.svelte`,
`styles/wizard.css`, `state/wizard.js` + переиспользуемое
(`TelegramSection`, `TelegramLogin`, `TgLoginDialog`, `LlmSection`, `CvFileRow`,
`ChoiceRow`, `SecretInput`, `SettingsSection`) и их оформление
(`button.css`, `input.css`, `choice-row.css`, `cv-file.css`, `settings.css`,
`settings-section.css`, `modal.css`, `status-pill.css`, `checkbox.css`).

Восемь экранов старого: `welcome`, `tg-creds`, `tg-code`, `tg-password`, `chat`,
`embed`, `cv`, `done`. Шесть новых: `welcome`, `telegram`, `chat`, `embed`, `cv`,
`done` — `tg-code` и `tg-password` свёрнуты в модальное окно.

## Не могло переехать (следствие переезда, не расхождение)

| что | почему |
|---|---|
| `qwebchannel.js` и весь бутстрап `new QWebChannel(...)` (стр. 293, 1209–1222) | Qt WebEngine снят вместе с PySide; мост теперь `$api/bridge.js` |
| `@font-face` Material Symbols из локального `fonts/material-symbols-outlined.ttf` (стр. 10–15) | заменён пакетом `material-symbols/outlined.css` (`main.js`); шрифт тот же |
| `<meta http-equiv="Content-Security-Policy">`, `X-Content-Type-Options` (стр. 5–6) | роль ушла в pywebview/vite |
| `escapeHtml`/`escapeAttr` (стр. 1144–1147) | Svelte экранирует сам |
| `.wiz-window { width: 100vw }` | размер окна теперь задаётся в `client/window.py`: `WINDOW_MIN = (900, 660)`, начальный равен наименьшему |
| `flatpickr` | в мастере не использовался вовсе — к этой области не относится |
