# Образец: `personal_rating`

Соседний проект того же человека, названный образцом 13 августа 2026:
`D:\Projects\Python Scripts\Personal Rating\personal_rating`. Здесь выписано
только то, что относится к нашему делу — устройство моста, устройство фронта и
способ их тестировать.

**Откуда числа.** Разведка 13 августа 2026, четыре агента по коду образца:
мост, фронт, точка входа с правилами, тесты. Своими глазами исходники образца не
читались — при опоре на конкретное решение место перечитывается заново.

## Схема целиком

```
main.py  →  BackendThread (свой поток, свой цикл asyncio)
                  ↓
            bridge/  ──── pywebview (js_api) ────  client/ (Svelte 5 + Vite)
                  ↓                                      ↓
            backend/                          api/ app/ components/ state/ styles/
     model ← {sources, storage} ← service
```

## Три решения, задающие всё остальное

**Граница слоёв совпадает с границей потоков.** Из `README.md` образца: «в потоке
интерфейса нет ни одного обращения к сети или диску». Бэкенд рождается **внутри**
чужого потока — движок SQLAlchemy привязан к циклу, в котором создан, — поэтому
сборка уезжает туда функцией: `BackendThread(lambda: build_backend(config))`.
Импортировать `backend.app` из `bridge/` нельзя, иначе в поток интерфейса
приехали бы и SQLAlchemy, и httpx.

**Границы держит тест, а не договорённость.** `tests/backend/test_layers.py`:

```python
BANNED_IN_BRIDGE   = {"sqlalchemy", "aiosqlite", "httpx", "alembic", "PIL", "bs4"}
BANNED_IN_BACKEND  = {"bridge", "webview", "pythonnet", "clr"}
ALLOWED_FROM_BACKEND = {"backend.model", "backend.config"}
```

Мосту из бэкенда открыты только типы границы и настройки — ни репозиториев, ни
сервисов, ни клиентов. Там же сторож `reaching_backend("backend/model", …) == []`:
слой типов не зависит ни от чего своего.

**Зависимость строго в одну сторону.** Из `docs/specs/2026-07-27-code-structure.md`:
«Зависимость строго в одну сторону: `client → backend → ничего`». И оттуда же —
«Папки `utils` нет».

## Мост: 14 файлов, 1193 строки

Шов двойной. **По предмету** — семь доменов, каждый класс-наследник `Domain`:
`library`, `marks`, `refs`, `feed`, `search`, `world`, `covers`. **По роду
работы** — инфраструктура: `thread` (189 строк, поток бэкенда), `serve` (свой
WSGI: раздаёт собранный фронт и обложки по HTTP), `window` (заводит окно
pywebview), `wire` (перевод значений в JSON-совместимый вид), `answer` (единый
конверт ответа), `kept` (значение, не проходящее через JSON, по номеру операции),
`api` (собирает семь доменов в дерево).

**Метод моста ничего не считает.** Целиком, из `marks.py`:

```python
def score(self, item_id: int, score: float | None) -> dict:
    now = datetime.now()
    return self._reply(
        lambda back: back.ratings.set_score(item_id, score, now))
```

Собрать вход, поставить часы, отдать в `_reply`. Ни SQL, ни ORM в мосте нет
нигде — только `back.<репозиторий>.<метод>`.

**`_reply` — единственная точка исхода.** Любой конец вызова превращается в
`{"ok": …}` или `{"fail": …}`: успех, отказ домена (`Denied`), таймаут,
отменённая операция, закрытое окно, чужое исключение с записью трассировки.

**Метод становится доступен из JS без декоратора** — соглашением pywebview:
рефлексией по `dir()`, мимо имён с подчёркиванием, с рекурсией в атрибуты-объекты.
Поэтому дерево доменов в `Api.__init__` и есть регистрация поверхности, а из JS
это `pywebview.api.feed.page(...)`.

**Байты через канал не ходят.** `wire` бросает `TypeError` на `bytes`, обложки
идут отдельным HTTP-адресом `/poster` в `serve.py`.

## Фронт: Svelte 5 + Vite, пять слоёв

| Слой | Файлов | Что там |
|---|---|---|
| `api/` | 2 | `bridge.js` — **единственное место, знающее про `window.pywebview`** |
| `app/` | 18 | экраны и модальные окна плюс вынесенная из них логика своими `.js` рядом |
| `components/` | 29 | переиспользуемые виджеты |
| `state/` | 21 | чистая логика и данные без разметки |
| `styles/` | 30 | по файлу CSS на компонент плюс `palette.css` |

Точка входа — `index.html` на 12 строк: `<div id="root">` и один модуль.
`main.js` (61 строка) ввозит шрифт, иконки, `App.svelte`, затем тридцать файлов
оформления поимённо (палитра первой) и монтирует приложение.

**Направление знания.** `app` ходит во всё; `components` ходит в `state` и
`styles`, но **ни один компонент не знает про `api`** — за мост ходят только
экраны; `state` ввозит только другой `state`. Слои объявлены машине в
`.claude/clean.json` образца:

```json
"front": {
  "scope": "client", "styles": "styles",
  "allowed": {"app": ["components", "state", "api", "styles"],
              "components": ["state", "styles"],
              "state": [], "api": [], "styles": []},
  "aliases": {"$styles": "styles", "$components": "components",
              "$state": "state", "$api": "api"},
  "palette": ["styles/palette.css"]
}
```

**Цвет живёт в одном файле.** `styles/palette.css`, 119 строк, и по месту пишется
только `var()`. Проверка на цвет мимо палитры оттого и работает.

**Собранный `dist/` раздаёт сам мост** — `serve.py` ищет папку по имени, а Vite
собирает с относительным базовым путём.

## Как тестируются мост и веб

Ради этого разведка и затевалась: у нас оба слоя не покрыты вовсе.

**Мост — 198 тестов, 15 файлов, 3089 строк.** Настоящий бэкенд не собирается
**никогда**, окно pywebview не поднимается ни разу: у бэкенда база, миграции и
шесть сетевых клиентов, а предмет проверки — граница потоков и обёртка. Домены
зовут напрямую питоном, поверх двух разных двойников:

- **`FakeBackend`** — двойник поведения: настоящие корутины со счётчиками и
  `asyncio.Event` вместо `sleep`;
- **`Asked`** — двойник записи вызовов через `__getattr__`: имя собирается по
  цепочке атрибутов, `spy.posters.store_upload(...)` ложится в лог как
  `("posters.store_upload", args, kwargs)`, а ответ берётся из словаря — туда же
  кладут исключение, если нужен отказ.

**Веб — 311 проверок, 27 файлов, Vitest, окружение `node`.** Ни jsdom, ни
браузера, ни отрисовки. Компоненты `.svelte` не тестируются вовсе — тестируется
то, что вынуто из них в `state/` и `app/*.js`, плюс `api/bridge.js`. Мост
подделан файлом `tests/web/fake.js`: он кладёт `globalThis.window = { pywebview:
{ api } }`, строит `api.домен.метод` из плоского словаря ответов и пишет лог
вызовов. Там же `bare()` — окно, куда мост ещё не внедрён, и `slow()` — для
устаревших ответов и гонок.

**Покрытие берётся не умением гонять браузер, а тем, что из разметки вынуто
всё проверяемое без неё.**

**Шов между языками сторожит отдельный тест.** `test_page_contract.py` (400
строк) читает исходники `client/*.js` регулярками и сверяет с датаклассами и
перечислениями бэкенда — по его докстроке, «питон не читает `client/`, Vitest не
читает `bridge/`», и опечатку в имени метода иначе не поймает ничто.

## Размеры

Файлов свыше 500 строк в боевом коде образца нет ни одного. Крупнейшее:
`service/merging.py` — 302, `bridge/thread.py` — 189, `app/App.svelte` — 388.
Функций свыше сорока строк почти нет; единственное записанное отступление —
`build_backend()` на 65 строк, композиционный корень.

| | Образец | У нас |
|---|---|---|
| Мост | 14 файлов, 1193 строки | один файл, 4469 |
| Канал | pywebview, `js_api` рефлексией | Qt WebChannel |
| Фронт | Svelte 5 + Vite, 5 слоёв, максимум 388 строк | `main.html` 15628 строк |
| Тестов на мост | 198 | 0 |
| Тестов на веб | 311 | 0 |
| Слои фронта объявлены машине | да | нет раздела `front` в `clean.json` |

**Догадка, которую надо проверить чтением:** мост образца тонкий не сам по себе,
а потому что бэкенд отдаёт готовые типы границы и мосту остаётся позвать. Наши
4469 строк, вероятно, толстые оттого, что логика живёт в них. `client/bridge.py`
для этой записи не читался — гипотеза, а не находка.

**Что видно и без чтения:** переход на pywebview и переход на Svelte — не один
пункт. Заменить канал, оставив монолитный HTML, можно; но тестируемость фронта,
ради которой всё и затевается, от этого не появится — тестировать нечего, пока
логика не вынута из разметки.
