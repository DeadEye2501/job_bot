## П1. Инструмент мутаций

Файлы: `tools/mutate.py`, `tools/mutations/*` (26 файлов, 634 поломки).

Решение проекта — мутации не гонять. Пункты о состоянии набора, не о возобновлении
прогонов. Сам `tools/mutate.py` устроен добросовестно: восстановление в `finally` на
каждую поломку, байт-точная сверка со снимком, отказ работать на грязном дереве.

**Числами.** Из 634 поломок реально работают **305 (48%)**, 113 (18%) молчат только
из-за разошедшегося допущения о переводе строк, 215 (34%) устарели по существу. Сутки
назад было 399/67/168 — набор продолжает протухать без присмотра.

- [ ] **решение человека** — чинить набор или снести его вместе с инструментом. Всё
  ниже имеет смысл только при первом ответе

Мутация **применится**, тест упадёт с `NameError`, и инструмент отчитается «поймана» по чужой причине — маскируя дыру, если она есть

## П2. Документ прошлой ревизии

Файл: `docs/ревизия/находки.md`.

Прошлая ревизия опиралась на этот файл как на источник; в нём нашлось пять
неточностей и три записи, которые надо уточнить по факту.

- [ ] `:216` — «во всём дереве ноль подавлений» противоречит строке 304 («в боевом коде ни одного, в стенде их десять»). Устаревшая копия — та, что несёт довод, по которому семь длинных подписей оставлены без подавления
- [ ] `:244` — «похудели с 383 строк до 262»: в файле 260 строк, и файл кончается переводом строки, так что промаха на единицу нет. То же число повторено в сообщении коммита, и стоит оно под заголовком «Измерено, а не на глаз»
- [ ] `:305-306` — обе половины оговорки неверны: два из десяти подавлений стоят **до** подмены хранилища ключей (`tests/conftest.py:24,26` против `:35`), и только эти два несут объяснение на строке; «все E402» обходит `:45`, где стоит `# noqa: E402, F401`
- [ ] `:240` — «карточка отдаёт свой зов» описывает договор наоборот: компонент настаивает на двух зовах, и сторож проверяет их порознь
- [ ] `:238` — запись «Сделано.» закрывает находку о дублях, пока два бо́льших слоя той же дубли не записаны (чип «В blacklist» — шесть копий, обработчики `block`/`unblock` — почти близнецы с разошедшимся третьим вариантом)
- [ ] открытый пункт «долгий FloodWait замораживает цикл бота» — описано иначе, чем есть: Pyrogram сам пережидает просьбы не длиннее `sleep_threshold`, до сна в `dm_backfill.py:85-93` выполнение не доходит, цикл не замерзает. Пересмотреть приоритет
- [ ] открытый пункт «мёртвые `check_chat`/`check_embed`» — они не мёртвые, их **нет**: обе слиты в `check_model`
- [ ] открытый пункт «шва имён между мостом и ботом нет» — шов есть (`tests/client/test_bot_contract.py`), но покрывает только имена подделки и не покрывает три зова (правка — в `Т3`)
