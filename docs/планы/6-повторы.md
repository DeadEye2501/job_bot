# План 6. Повторы фронта, найденные мимо плана 3 — 5 слайсов

Собран из находок рецензентов по повторам, работавших на слайсах Ф1–Ф5 плана 3.
В план 3 эти группы не входили: рецензент ищет по картам во всём проекте сразу и
находит то, чего не касался ни один слайс. Всё, что план 3 требовал свести,
сведено и сюда не переписано.

Пометки: **крупный** — места уже разошлись поведением или их больше трёх ·
**средний** — совпадают дословно, разойдутся при первой правке · **мелкий** —
две-три строки.

Места названы файлами; номера строк стоят там, где рецензент сверял их
построчно. Остальные уехали за время работы плана 3 и сверяются на слайсе заново.
