# Планируется

## Автоматическое выполнение тестовых заданий

Отдельная фича, включается по желанию.

Когда приходит тестовое задание: заводится новая папка, в ней создаётся окружение, подгружаются нужные скиллы, и задание выполняется. Готовое решение заливается в публичный репозиторий на GitHub, а HR получает ссылку с описанием выполненного.
