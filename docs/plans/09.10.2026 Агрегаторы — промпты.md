# Агрегаторы — промпты: план реализации

> **Для исполнителя:** работа идёт слайсами по скиллу `free-hands:keeping-code-clean`:
> тест до кода и виден красным → код → карты → ревью агентами через
> `superpowers:requesting-code-review` → правки → коммит. Шаги отмечаются
> галочками (`- [ ]`).

**Цель:** то, что агент и чат-модель знают и по каким правилам работают при
поиске и откликах вне Telegram. Анкета для агента со стажем, посчитанным
кодом. Семь промптов. Письмо и тема чат-моделью и сверка письма.

**Устройство:** общий стаж берётся готовым счётчиком (`_years_in_it` из
`profile_block.py`, вынесенным в домен), рядом — стаж по навыку той же
арифметикой.
Анкета для агента собирается своим модулем репозитория, а не
`profile_block.py`. Тексты промптов агента живут пакетом `backend/agent/prompts/`.
Там же сборщики стартовых заданий: код подставляет в них данные задачи, а
системные промпты от человека не зависят вовсе. Письмо вне Telegram пишет
новый промпт чат-модели (`backend/llm/agent_letter.py`), а сверяет общая сверка
фактов `factcheck_cover_letter`, дополненная правилом про перевод.
Правила голоса человека — тон, род, латиница, факты только из анкеты —
объявлены по разу в `backend/llm/rules.py`; рамка агента и правила письма
собираются из них, и ни один системный промпт не получает правило дважды.

**Стек:** Python 3, SQLAlchemy 2 async, pytest + pytest-asyncio, поддельный
поставщик модели `tests/fakes/llm.py`.

**Спека:** `docs/specs/09.10.2026 Агрегаторы — промпты.md`

**Зависит от:** плана `09.10.2026 Агрегаторы — данные.md`, задача 1 — колонки
анкеты `expected_salary*`, `*_latin`, `gender` и перечисления `Gender`,
`SalaryPeriod`, `ApplicationVia`; задача 10 — набор `LETTER_WRITERS` в
`backend/runtime_settings.py`.
**Потребитель:** план `09.10.2026 Агрегаторы — поток.md`. Инструменты `profile`,
`letter`, сессии агента берут отсюда всё, что названо в «Интерфейсах». Текст
вакансии для откликателя собирает поток (`describe_vacancy`, его задача 8);
`applier_task` берёт его готовым.

## Глобальные ограничения

- Тесты гоняются так: `pipenv run python -m pytest <путь> -q`.
- Файл — не больше 500 строк, функция — не больше 40 строк и 4 параметров.
- Промпты обезличены. Ни профессии, ни страны, ни личности владельца. Примеры —
  из разных ремёсел. Вместо имён, ников и адресов — заглушки. Ни одного
  литерала с разбираемого случая.
- Правило, а не таблица: промпт описывает цель и принцип, а не пороги.
- Язык промптов — русский.
- Слоты в промптах заполняются `.replace("{SLOT}", …)`, не `.format`: в
  промптах бывают буквальные фигурные скобки.
- Данные чужого происхождения (текст вакансии) уходят модели обрамлёнными
  (`backend/llm/external.py`).
- Комментарии — только довод. «Коммит» — `git add . && git commit` с проверкой,
  что личные данные в git не попали. Сообщение кончается строкой
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Где смотреть при ревью

1. Навык только с прошлой работы. Ждём, что его стаж кончается вместе с этой
   работой, а не растёт до сегодня (задача 1).
2. Навык, не привязанный ни к одному месту работы. Ждём «без срока», а не 0
   (задача 2).
3. Анкета без пола, без латиницы и без зарплаты. Ждём, что анкета для агента
   прямо говорит «не указано», а не пропускает строку молча: агенту так видно,
   что поле пусто, а не забыто (задача 2).
4. Чат-модель вернула письмо длиннее поля формы. Ждём отказ с причиной без
   траты зова на сверку; повтор — один, новым зовом `letter` от откликателя
   (задачи 4, 5).
5. Письмо на другом языке, чем анкета. Ждём, что сверка не отбивает перевод
   фактов как выдумку: правило в промпте сверки, проверяется живым прогоном
   (задача 6).

```python
"""Сроки мест работы: период и стаж, общий и по навыку."""

from datetime import date


def place_period(place) -> str:
    """Период места работы: «ММ.ГГГГ — ММ.ГГГГ» или «— настоящее время».

    Одна строка на все анкеты: письмо в Telegram и агент видят даты одинаково.
    """
    end = place.end_date.strftime("%m.%Y") if place.end_date else "настоящее время"
    return f"{place.start_date.strftime('%m.%Y')} — {end}"


def full_years(start: date, end: date) -> int:
    """Полных лет между датами. Отрицательным не бывает: место, начатое
    «завтра», — опечатка, а не отрицательный стаж."""
    years = end.year - start.year - ((end.month, end.day) < (start.month, start.day))
    return max(years, 0)


def years_in_it(experiences, today: date) -> int:
    """Сколько лет опыта — от самого раннего места работы до сегодня.

    Считается по началу, а не по сумме сроков: перерывы между местами опытом
    быть не перестают, а вычесть их значило бы спорить с тем, как этот срок
    называют в резюме.
    """
    return full_years(min(e.start_date for e in experiences), today)


def skill_years(experiences, today: date) -> int:
    """Стаж по навыку — от первого места, где он назван, до конца последнего.

    Правило то же, что у общего стажа, кроме конца: навык с прошлой работы
    не растёт до сегодня.
    """
    end = max(e.end_date or today for e in experiences)
    return full_years(min(e.start_date for e in experiences), end)
```

```python
"""Анкета человека целиком, как её видит агент: со стажем общим и по навыкам."""

from datetime import date

from sqlalchemy.ext.asyncio import AsyncSession

from backend.domain.salary import salary_text
from backend.domain.tenure import place_period, skill_years, years_in_it
from backend.llm.candidate import CandidateLanguage, format_languages
from backend.models import Gender, SalaryPeriod
from backend.repository.profile import get_profile
from backend.repository.profile_experience import list_experience
from backend.repository.profile_languages import list_profile_languages
from backend.repository.profile_skills import list_skills

_GENDER = {Gender.MALE: "мужской", Gender.FEMALE: "женский"}
_PERIOD = {SalaryPeriod.HOUR: "в час", SalaryPeriod.MONTH: "в месяц", SalaryPeriod.YEAR: "в год"}


async def build_agent_profile(session: AsyncSession, today: date) -> str:
    """Анкета для агента. Пустые поля названы пустыми: агенту видно, что их нет."""
    profile = await get_profile(session)
    if profile is None:
        return ""
    places = await list_experience(session)
    skills = await list_skills(session)
    languages = await list_profile_languages(session)
    return "\n".join([
        *_person_lines(profile, languages),
        f"Общий стаж: {_years(years_in_it(places, today)) if places else 'нет мест работы'}",
        "Навыки:", *_skill_lines(skills, places, today),
        "Опыт работы:", *_place_lines(places),
        f"Предпочтения: {profile.free_preferences or 'не указаны'}",
    ])


def _person_lines(p, languages) -> list[str]:
    spoken = format_languages([CandidateLanguage(one.language, one.level) for one in languages])
    return [
        f"Имя: {p.first_name}",
        f"Фамилия: {p.last_name}",
        f"Имя латиницей: {p.first_name_latin or 'не указано'}",
        f"Фамилия латиницей: {p.last_name_latin or 'не указана'}",
        f"Пол: {_GENDER.get(p.gender, 'не указан')}",
        f"Должность: {p.title}",
        f"Грейды: {', '.join(p.grades) or 'не указаны'}",
        f"Формат работы: {', '.join(p.work_format) or 'не указан'}",
        f"Место: {p.location or 'не указано'}",
        f"Языки: {spoken}",
        f"Почта: {p.email}",
        f"Телефон: {p.phone or 'не указан'}",
        f"Telegram: {p.telegram_username or 'не указан'}",
        f"GitHub: {p.github_url or 'не указан'}",
        f"Образование: {p.education or 'не указано'}",
        f"Ожидаемая зарплата: {_salary(p)}",
    ]


def _salary(p) -> str:
    if p.expected_salary is None:
        return "не указана"
    amount = p.expected_salary
    money = salary_text(amount, amount, p.expected_salary_currency or "валюта не указана")
    period = _PERIOD.get(p.expected_salary_period, "период не указан")
    return f"{money} {period}, на руки"


def _skill_lines(skills, places, today: date) -> list[str]:
    lines = []
    for skill in skills:
        named = [p for p in places if skill in p.skills]
        term = f"стаж {_years(skill_years(named, today))}" if named else (
            "стаж не привязан к местам работы"
        )
        lines.append(f"- {skill.name} — уровень {skill.level}, {term}")
    return lines


def _place_lines(places) -> list[str]:
    lines = []
    for p in places:
        lines.append(f"- {p.company}, {p.role}, {place_period(p)}")
        lines += [f"  Обязанность: {one}" for one in p.responsibilities]
        lines += [f"  Достижение: {one}" for one in p.achievements]
    return lines


def _years(years: int) -> str:
    return f"{years}+ г."
```

```python
        f"Сегодня: {today.isoformat()}",
    ])

    return f"Прошлый обход начался: {last_run.strftime('%Y-%m-%d %H:%M')} UTC"
```

```python
"""Письмо и тема для отклика вне Telegram: пишет чат-модель, проверяет сверка фактов."""

import logging
from dataclasses import dataclass

from adapters.lm_chat import ChatRequest, chat
from backend.llm.answers import ONLY_JSON, json_object, str_or_none
from backend.llm.external import external_block
from backend.llm.factcheck import factcheck_cover_letter
from backend.llm.rules import LETTER_RULES, has_placeholder

logger = logging.getLogger(__name__)

MAX_LETTER_TOKENS = 2500

WRITE_LETTER_PROMPT = """Ты пишешь сопроводительное письмо к отклику на вакансию от имени человека и тему этого письма. Письмо читает работодатель.

Язык письма и темы: {LANGUAGE}.
{LIMIT}

""" + LETTER_RULES + """
Анкета человека:
{PROFILE}

Верни JSON-объект: {"subject": "тема", "body": "текст письма"}
""" + ONLY_JSON


@dataclass(frozen=True)
class Letter:
    subject: str
    body: str


@dataclass(frozen=True)
class LetterAsk:
    profile_text: str
    title: str
    vacancy_text: str
    language: str
    limit: int | None


async def write_letter(ask: LetterAsk, client, model: str) -> tuple[Letter | None, list[str]]:
    """Одна попытка: письмо, прошедшее проверку и сверку, или пусто и замечания."""
    reply = await chat(client, model, _request(ask), logger)
    letter = _letter_of(reply.text)
    if letter is None:
        return None, ["модель не вернула письмо"]
    ok, issues = await check_letter(ask, letter, client, model)
    return (letter, []) if ok else (None, issues)


async def check_letter(ask: LetterAsk, letter: Letter, client, model: str) -> tuple[bool, list[str]]:
    """Длина, заглушки, затем сверка фактов вместе с темой — та же, что у писем приложения."""
    trouble = _trouble(letter, ask.limit)
    if trouble is not None:
        return False, [trouble]
    return await factcheck_cover_letter(
        ask.profile_text, f"{letter.subject}\n\n{letter.body}", client, model, about=ask.title
    )


def _request(ask: LetterAsk) -> ChatRequest:
    limit = f"Предел длины письма: {ask.limit} знаков." if ask.limit else "Предела длины нет; пиши коротко."
    system = (
        WRITE_LETTER_PROMPT
        .replace("{LANGUAGE}", ask.language)
        .replace("{LIMIT}", limit)
        .replace("{PROFILE}", ask.profile_text)
    )
    vacancy = external_block(f"{ask.title}\n\n{ask.vacancy_text}", "текст вакансии")
    return ChatRequest(
        purpose="write_agent_letter",
        messages=[{"role": "system", "content": system}, {"role": "user", "content": vacancy}],
        max_tokens=MAX_LETTER_TOKENS, temperature=0.5,
    )


def _letter_of(text: str | None) -> Letter | None:
    if text is None:
        return None
    obj = json_object(text, logger, "write_agent_letter")
    if not isinstance(obj, dict):
        return None
    subject, body = obj.get("subject"), str_or_none(obj.get("body"))
    if not isinstance(subject, str) or body is None:
        return None
    return Letter(_short_dash(subject.strip()), _short_dash(body))


def _short_dash(text: str) -> str:
    return text.replace("—", "-")


def _trouble(letter: Letter, limit: int | None) -> str | None:
    if limit and len(letter.body) > limit:
        return f"длиннее поля: {len(letter.body)} знаков из {limit}"
    for text in (letter.subject, letter.body):
        if has_placeholder(text):
            return "в теме или письме осталась заглушка"
    return None
```

общий `ONLY_JSON`, образец объекта перед ним свой. Пустое тело отсеивает
`str_or_none`; пустая тема допустима.

```python
    """Осталась ли в тексте заглушка, которую модель сочинила сама.

    Одна проверка на оба письма: разойдись наборы скобок, письмо, отбитое в

    угловые — образцом: проверка по одному знаку цепляла бы стрелки и смайлы
    (`=>`, `->`, `<3`).
    """
```
