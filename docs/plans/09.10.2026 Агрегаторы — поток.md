# Агрегаторы — поток: план реализации

> **Для исполнителя:** работа идёт слайсами по скиллу `free-hands:keeping-code-clean`:
> тест до кода и виден красным → код → карты → ревью агентами через
> `superpowers:requesting-code-review` → правки → коммит. Шаги отмечаются
> галочками (`- [ ]`).

**Цель:** приложение ищет вакансии на агрегаторах и по всей сети агентом,
пропускает их через свой конвейер и откликается на них агентом — на сайте,
формой работодателя или письмом.

**Устройство.** Пять слоёв, каждый знает только нижние.
1. **Внешнее** (`adapters/`): браузер на Playwright, MCP-сервер, процесс
   Claude Code как водитель агента, отправка почты.
2. **Данные** (`backend/repository/`): агрегаторы, почта, отклики.
3. **Инструменты агента** (`backend/agent/tools_*.py`): обычные async-функции
   над данными и браузером, привязанные к задаче сессии. Про MCP и про
   водителя они не знают.
4. **Обход** (`backend/flows/aggregator_*.py`): фазы, порядок способов,
   пауза на человека. Сессию агента он получает функцией `run_session` из
   набора `AgentKit`, а в тестах — поддельной функцией по сценарию.
5. **Бот и мост** (`backend/bot/aggregators.py`, `client/bridge/aggregators.py`):
   место прогона, режимы, кнопки, вести окну.

**Стек:** Python 3.13, SQLAlchemy 2 async, Alembic, Playwright for Python
(async API), библиотека `mcp` (FastMCP, транспорт streamable HTTP) поверх
`uvicorn`, `smtplib`. Claude Code CLI в режиме `-p` со stream-json.

**Спека:** `docs/specs/09.10.2026 Агрегаторы — поток.md`

**Зависит от:**
- `docs/plans/09.10.2026 Агрегаторы — данные.md` — вся схема; `contact_key`;
  `replace_parsed_contact`; `record_trash_event(session, vacancy, reason)`;
  настройки `aggregator_backfill_limit`, `show_browser`, `letter_writer` и

## Глобальные ограничения

- Тесты гоняются так: `pipenv run python -m pytest <путь> -q`.
- Файл — не больше 500 строк, функция — не больше 40 строк, 3 уровней
  вложенности и 4 параметров.
- Широкий `except` — только с `logger.exception` или пробросом.
- Тексты, которые мост отдаёт окну, — на «вы», без транслита.
- Без живого сайта и без Claude Code в тестах: браузер, водитель и SMTP —
  поддельные.
- Живые прогоны и сборка exe в план не входят: их делает человек после.
- Комментарии — только довод. «Коммит» — `git add . && git commit` с проверкой,
  что личные данные в git не попали. Сообщение кончается строкой
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Фронта в плане нет: окно — `docs/specs/09.10.2026 Агрегаторы — окно.md`.
  Здесь только мост.

```python
def tie_children_named(name: str) -> int:
    """Привязать дочерние процессы приложения с этим именем. Ответ — сколько привязано.

    Публичного способа узнать процесс драйвера Playwright нет. Свой процесс

    count = 0
    for pid, image in _children():
        if image.lower() == name.lower():
            tie_to_app(pid)
            count += 1
    return count


def _children() -> list[tuple[int, str]]:
    """Дочерние процессы приложения: номер и имя файла — по снимку процессов Windows."""
```

**Интерфейсы (выдаёт):**
- `BROWSER_DIR: Path`.
- `InstalledBrowser(name: str, channel: str | None, executable: Path | None)`.
- `find_browser() -> InstalledBrowser | None` — порядок Chrome → Opera → Brave →
  Vivaldi → Яндекс.Браузер → Edge.
- `BrowserHost(browser: InstalledBrowser, always_visible: bool)`:
  - `async open_profile(profile_id: int) -> None` — профиль `BROWSER_DIR/<id>`;
    прежний закрывается; драйвер при первом запуске привязывается к
    приложению (`tie_children_named("node.exe")`);

    новую, уводит агента туда. Окно закрыто человеком — профиль переоткрывается
    на последнем известном адресе;
  - `async show() -> None` / `async hide_back() -> None` — развернуть окно и
    свернуть обратно, если так велит настройка;
  - `async clear_cache() -> None` — сброс кеша через CDP, куки и вход остаются;

  - `async close() -> None`.
- `remove_profile(profile_id: int) -> None` — снести каталог профиля.

```python
"""Браузер человека на движке Chromium под управлением Playwright."""

import logging
import os
import shutil
from dataclasses import dataclass
from pathlib import Path

from config import get_data_dir

logger = logging.getLogger(__name__)

BROWSER_DIR = get_data_dir() / "browser"

_PROGRAMS = ("PROGRAMFILES", "PROGRAMFILES(X86)", "LOCALAPPDATA")


@dataclass(frozen=True)
class InstalledBrowser:
    name: str
    channel: str | None
    executable: Path | None


def find_browser() -> InstalledBrowser | None:
    """Первый найденный: Chrome, Opera, Brave, Vivaldi, Яндекс.Браузер, Edge.

    Chrome и Edge Playwright водит по имени канала, остальных — по пути к
    исполняемому файлу.
    """
    for found in (
        _channel("Chrome", "chrome", "Google/Chrome/Application/chrome.exe"),
        _opera(),
        _by_path("Brave", "BraveSoftware/Brave-Browser/Application/brave.exe"),
        _by_path("Vivaldi", "Vivaldi/Application/vivaldi.exe"),
        _by_path("Яндекс.Браузер", "Yandex/YandexBrowser/Application/browser.exe"),
        _channel("Edge", "msedge", "Microsoft/Edge/Application/msedge.exe"),
    ):
        if found is not None:
            return found
    return None


def _candidates(relative: str) -> list[Path]:
    return [Path(os.environ[root]) / relative for root in _PROGRAMS if os.environ.get(root)]


def _first(relative: str) -> Path | None:
    return next((path for path in _candidates(relative) if path.is_file()), None)


def _channel(name: str, channel: str, relative: str) -> InstalledBrowser | None:
    return InstalledBrowser(name, channel, None) if _first(relative) else None


def _by_path(name: str, relative: str) -> InstalledBrowser | None:
    found = _first(relative)
    return InstalledBrowser(name, None, found) if found else None


def _opera() -> InstalledBrowser | None:
    """Opera: настоящий opera.exe лежит в папке версии, а верхний — запускающая обёртка."""
    for home in _candidates("Programs/Opera"):
        versions = sorted(
            (d for d in home.glob("*") if d.is_dir() and (d / "opera.exe").is_file()),
            key=lambda d: [int(p) for p in d.name.split(".") if p.isdigit()],
        )
        if versions:
            return InstalledBrowser("Opera", None, versions[-1] / "opera.exe")
    return None


def remove_profile(profile_id: int) -> None:
    """Снести профиль браузера агрегатора — при удалении агрегатора."""
    try:
        shutil.rmtree(BROWSER_DIR / str(profile_id))
    except FileNotFoundError:
        return
    except OSError:
        logger.exception("профиль браузера %d не удалён", profile_id)
```

```python
class BrowserHost:
    """Один браузер приложения: профиль за профилем, развёрнутый или свёрнутый."""

    def __init__(self, browser: InstalledBrowser, always_visible: bool) -> None:
        self._browser = browser
        self._always_visible = always_visible
        self._playwright = None
        self._context = None
        self._profile_id: int | None = None
        self._last_url = "about:blank"

    async def open_profile(self, profile_id: int) -> None:
        if self._profile_id == profile_id and self._context is not None:
            return
        await self._close_context()
        self._profile_id = profile_id
        await self._launch()

    async def page(self):
        """Последняя вкладка. Окно закрыл человек — профиль переоткрывается там же."""
        if self._context is None or not self._context.pages:
            await self._close_context()
            await self._launch()
        current = self._context.pages[-1]
        self._last_url = current.url
        return current
```

```python
    """Ссылка принадлежит сайту, если её хост равен его хосту или кончается на точку и его хост.
```

```python
"""Ведение записей об агрегаторах."""

from datetime import datetime

from sqlalchemy import func, or_, select, update
from sqlalchemy.ext.asyncio import AsyncSession

from backend.domain.hosts import normalize_host
from backend.models import Aggregator, Application, TrashEvent, Vacancy
from backend.repository.vacancies_life import repoint_vacancies

WEB_SEARCH_NAME = "Поиск по сети"


async def create_aggregator(session: AsyncSession, address: str) -> tuple[Aggregator | None, str]:
    """Завести агрегатор по адресу, набранному как угодно. Новый выключен и без входа."""
    host = normalize_host(address)
    if not host:
        return None, "invalid"
    known = await session.scalar(select(Aggregator).where(Aggregator.host == host))
    if known is not None:
        return known, "exists"
    row = Aggregator(name=host, host=host, is_active=False, is_logged_in=False)
    session.add(row)
    await session.flush()
    return row, "created"


async def list_aggregators(session: AsyncSession) -> list[Aggregator]:
    """Все источники-агрегаторы: «Поиск по сети» первым, дальше в порядке заведения."""
    return list((await session.scalars(
        select(Aggregator).order_by(Aggregator.host.is_not(None), Aggregator.id)
    )).all())


async def set_aggregator_active(session: AsyncSession, aggregator_id: int, active: bool) -> str:
    row = await session.get(Aggregator, aggregator_id)
    if row is None:
        return "missing"
    if active and not row.is_logged_in:
        return "not_logged_in"
    row.is_active = active
    return "ok"


async def set_logged_in(session: AsyncSession, aggregator_id: int, logged_in: bool) -> None:
    """Отметка входа. Включённость не трогает: без входа агрегатор просто не обходится."""
    row = await session.get(Aggregator, aggregator_id)
    if row is not None and row.host is not None:
        row.is_logged_in = logged_in


async def mark_run(session: AsyncSession, aggregator_id: int, started_at: datetime) -> None:
    row = await session.get(Aggregator, aggregator_id)
    if row is not None:
        row.last_run_at = started_at


async def applications_of(session: AsyncSession, aggregator_id: int) -> int:
    """Откликов, связанных с агрегатором, — их число окно называет перед удалением.

    Свои — и по вакансиям с него, и отклики его кнопкой на вакансии из других
    источников.
    """
    return int(await session.scalar(
        select(func.count(Application.id))
        .join(Vacancy, Vacancy.id == Application.vacancy_id)
        .where(or_(Vacancy.source_aggregator_id == aggregator_id,
                   Application.aggregator_id == aggregator_id))
    ) or 0)


async def delete_aggregator(session: AsyncSession, aggregator_id: int) -> str:
    """Удалить агрегатор. Вакансии, отклики и отметки о мусоре остаются, ссылка на него — нет.

    Как удаление канала (`delete_channel`): ссылки обнуляет код, правила
    «обнулить при удалении» у внешних ключей нет. Вакансии отвязывает общее
    `repoint_vacancies`; отклики и мусор — другие таблицы, и у каждой свой
    запрос: обобщать `repoint_vacancies` на любую модель его докстрока запрещает.
    """
    row = await session.get(Aggregator, aggregator_id)
    if row is None:
        return "missing"
    if row.host is None:
        return "protected"
    await repoint_vacancies(
        session, Vacancy.source_aggregator_id, absorbed_id=aggregator_id, survivor_id=None
    )
    await session.execute(
        update(Application).where(Application.aggregator_id == aggregator_id)
        .values(aggregator_id=None)
    )
    await session.execute(
        update(TrashEvent).where(TrashEvent.source_aggregator_id == aggregator_id)
        .values(source_aggregator_id=None)
    )
    await session.delete(row)
    return "ok"


async def round_sources(session: AsyncSession) -> list[Aggregator]:
    """Источники общего обхода: включённые агрегаторы со входом, затем «Поиск по сети»."""
    rows = (await session.scalars(
        select(Aggregator)
        .where(Aggregator.is_active.is_(True), Aggregator.is_logged_in.is_(True))
        .order_by(Aggregator.host.is_(None), Aggregator.id)
    )).all()
    return list(rows)
```

```python
"""Отправка письма по SMTP с вложением, под паролем приложения."""

import mimetypes
import smtplib
import ssl
from dataclasses import dataclass, field
from email.message import EmailMessage
from pathlib import Path

_TIMEOUT_SEC = 60


@dataclass(frozen=True)
class MailAccountConfig:
    address: str
    host: str
    port: int
    password: str = field(repr=False)


@dataclass(frozen=True)
class OutgoingMail:
    to: str
    subject: str
    body: str
    attachment: Path


def send_mail(account: MailAccountConfig, mail: OutgoingMail) -> None:
    """Отправить письмо. Ошибку сервера пробрасывает: отклик без письма не записывается."""
    message = EmailMessage()
    message["From"], message["To"], message["Subject"] = account.address, mail.to, mail.subject
    message.set_content(mail.body)
    kind = mimetypes.guess_type(mail.attachment.name)[0] or "application/octet-stream"
    main, sub = kind.split("/", 1)
    message.add_attachment(
        mail.attachment.read_bytes(), maintype=main, subtype=sub, filename=mail.attachment.name
    )
    with smtplib.SMTP_SSL(
        account.host, account.port, context=ssl.create_default_context(), timeout=_TIMEOUT_SEC
    ) as smtp:
        smtp.login(account.address, account.password)
        smtp.send_message(message)
```

пишется сразу, с тестом на поддельный `smtplib.SMTP`: при порте 587 позван

```python
from adapters.smtp_mail import MailAccountConfig
from backend.crypto import decrypt_or_none, encrypt_str
from backend.log_secrets import remember_secret
from backend.models import MailAccount

_GMAIL = ("smtp.gmail.com", 465)
_GMAIL_DOMAINS = ("@gmail.com", "@googlemail.com")


async def get_mail_account(session: AsyncSession) -> MailAccountConfig | None:
    """Почта, готовая к отправке, или пусто: без адреса, пароля или сервера писать нечем."""
    row = await session.get(MailAccount, 1)
    if row is None or not row.address or not row.password_encrypted:
        return None
    if not row.smtp_host or not row.smtp_port:
        return None
    password = decrypt_or_none(row.password_encrypted, "mail password")
    if not password:
        return None
    remember_secret(password)
    return MailAccountConfig(row.address, row.smtp_host, row.smtp_port, password)


@dataclass(frozen=True)

    address: str
    password: str | None = field(repr=False)
    host: str | None
    port: int | None


async def save_mail_account(session: AsyncSession, settings: MailSettings) -> None:
    """Записать почту. Пустой пароль — оставить прежний; у Gmail сервер подставляется сам."""
    row = await session.get(MailAccount, 1) or MailAccount(id=1)
    session.add(row)
    row.address = settings.address.strip() or None
    if settings.password:
        remember_secret(settings.password)
        row.password_encrypted = encrypt_str(settings.password)
    row.smtp_host, row.smtp_port = _server(row.address, settings.host, settings.port)


def _server(address: str | None, host: str | None, port: int | None) -> tuple[str | None, int | None]:
```

```python
"""Общие инструменты агента: анкета, отметка входа, итог сессии, неудача способа."""

from typing import Callable

from backend.agent.jobs import Applied, ApplyJob, Failed, Finished, LoginJob, SeekJob
from backend.agent.kit import AgentKit
from backend.repository.agent_profile import build_agent_profile
from backend.repository.aggregators import set_logged_in

_ALREADY_APPLIED = (
    "Отклик уже записан, итог не меняется: второй отклик ушёл бы тому же "
    "работодателю другим способом. Заверши работу."
)

_RESULTS = {
    LoginJob: {"done"},
    SeekJob: {"done", "failed"},
    ApplyJob: {"vacancy_closed", "platform_closed"},
}


def common_tools(kit: AgentKit, job) -> list[Callable]:
    """Инструменты, привязанные к задаче сессии: за её пределы они не выходят."""

    async def profile() -> str:
        """Анкета человека целиком, со стажем общим и по навыкам."""
        async with kit.pipeline.session_factory() as session:
            return await build_agent_profile(session, kit.today) or "Анкета не заполнена."

    async def finish(result: str, reason: str = "") -> str:
        """Итог сессии. Искатель: done или failed. Откликатель: vacancy_closed или platform_closed. Проверка входа: done."""
        if result not in _RESULTS[type(job)]:
            return f"Итога «{result}» у этой задачи не бывает: {', '.join(sorted(_RESULTS[type(job)]))}."
        if isinstance(job.outcome, Applied):
            return _ALREADY_APPLIED
        job.outcome = Finished(result, reason)
        return "Итог записан, работа окончена."

    tools = [profile, finish]
    aggregator_id = _login_target(job)
    if aggregator_id is not None:
        tools.append(_report_login(kit, aggregator_id))
    if isinstance(job, ApplyJob):
        tools.append(_report_failure(job))
    return tools


def _login_target(job) -> int | None:
    if isinstance(job, (LoginJob, SeekJob)):
        return job.source.id if job.source.host is not None else None
    return job.aggregator_id if job.method == "aggregator" else None


def _report_login(kit: AgentKit, aggregator_id: int) -> Callable:
    async def report_login(logged_in: bool) -> str:
        """Вошёл ли человек на сайт: true — вошёл, false — нет."""
        async with kit.pipeline.session_factory() as session:
            async with session.begin():
                await set_logged_in(session, aggregator_id, logged_in)
        return "Отметка входа записана."

    return report_login


def _report_failure(job: ApplyJob) -> Callable:
    async def report_failure(reason: str) -> str:
        """Отклик этим способом не удался; причина — коротко, по-русски."""
        if isinstance(job.outcome, Applied):
            return _ALREADY_APPLIED
        job.outcome = Failed(reason)
        return "Неудача записана. Приложение попробует другой способ."

    return report_failure
```

```python
"""Ожидание человека: капча или слетевший вход. Срок — час на весь обход."""

import asyncio
import time
from typing import Callable

LIMIT_SEC = 3600.0


class HumanGate:
    def __init__(self, on_needed: Callable[[str, str], None], on_resolved: Callable[[], None],
                 limit_sec: float = LIMIT_SEC) -> None:
        self._on_needed, self._on_resolved = on_needed, on_resolved
        self._limit = limit_sec
        self._done = asyncio.Event()
        self._deadline: float | None = None
        self._answer: str | None = None
        self.expired = asyncio.Event()

    async def wait(self, kind: str, host: str, browser) -> str:
        """Ждать человека. Повторный зов во время ожидания ждёт того же срока."""
        if self._deadline is None:
            self._deadline = time.monotonic() + self._limit
            self._done.clear()
            await browser.show()
            self._on_needed(kind, host)
        try:
            await asyncio.wait_for(self._done.wait(), max(self._deadline - time.monotonic(), 0))
        except TimeoutError:
            self.expired.set()
            return "срок вышел; заверши работу"
        return await self._take(browser)

    def resolve(self) -> None:
        """«Готово» из окна. Зовётся на цикле бота, а не из потока окна."""
        if self._deadline is not None:
            self._answer = "готово"
            self._done.set()
            self._on_resolved()

    def abort(self) -> None:
        """Обход остановлен: ждущий вызов возвращается сразу, а не через час."""
        if self._deadline is not None:
            self._answer = "обход остановлен; заверши работу"
            self._done.set()

    def reset(self) -> None:
        self._deadline, self._answer = None, None
        self._done.clear()
        self.expired.clear()

    async def _take(self, browser) -> str:
        """Ответ забирает один вызов; он же прячет браузер — второй ожидавший
        повтор оборванного вызова получает «готово» без второго переноса окна."""
        answer, self._answer = self._answer, None
        self._deadline = None
        if answer is None:
            return "готово"
        if answer == "готово":
            await browser.hide_back()
        return answer
```

```python
import asyncio
import logging

from backend.flows import parse
from backend.task_stop import put_out

logger = logging.getLogger(__name__)


class ParseQueue:
    """Разбирает по одной в порядке поступления; одна сломанная не держит остальных."""

    def __init__(self, pipeline) -> None:
        self._pipeline = pipeline
        self._items: asyncio.Queue[tuple[int, str]] = asyncio.Queue()
        self._worker = asyncio.create_task(self._work())

    def put(self, vacancy_id: int, text: str) -> None:
        self._items.put_nowait((vacancy_id, text))

    async def drain(self) -> None:
        await self._items.join()
        await self.stop()

    async def stop(self) -> None:
        await put_out(self._worker)

    async def _work(self) -> None:
        while True:
            vacancy_id, text = await self._items.get()
            try:
                await parse.parse_and_update_vacancy(self._pipeline, vacancy_id, text, None)
            except Exception:
                logger.exception("разбор найденной вакансии %d не удался", vacancy_id)
            finally:
                self._items.task_done()
```

```python
@dataclass(frozen=True)
class Match:
    kind: str                     # "new" | "parsed" | "unparsed"
    vacancy_id: int | None
    embedding: list[float] | None


async def known_or_new(pipeline, text: str, what: str) -> Match | None:
    """Вектор текста и похожая заведённая вакансия. Пусто — модель не ответила.

    Молчание поставщика (`ProviderIsSilent`) пробрасывается: зовущему решать,
    отказ это или пропуск.
    """
    embedding = await embed_text(pipeline, text, what)
    if embedding is None:
        return None
    similar = await similar_vacancy_id(pipeline, embedding)
    if similar is None:
        return Match("new", None, embedding)
    unparsed = await parse.is_unparsed_vacancy(pipeline, similar)
    return Match("unparsed" if unparsed else "parsed", similar, embedding)
```

```python
@dataclass(frozen=True)
class _Page:
    text: str
    url: str
    published: str
    contacts: list[str]


async def _submit(kit: AgentKit, job: SeekJob, queue, page: _Page) -> str:
    key = source_key(page.url, job.source.host)
    if key is None:
        return "пропущена: адрес не с этого источника; иди дальше"
    if await _known(kit, job.source.id, key):
        return _left("повтор", job)
    if job.submitted >= job.limit:
        return "предел исчерпан; заверши работу: finish с result=\"done\""
    try:
        match = await embeddings.known_or_new(kit.pipeline, page.text, WHAT)
    except embeddings.ProviderIsSilent:
        job.refused = True
        return "отказ: модель эмбеддингов не отвечает; заверши работу: finish с result=\"failed\""
    if match is None:
        return "пропущена: по тексту не вышло отпечатка; иди дальше"
    if match.kind == "unparsed":
        queue.put(match.vacancy_id, page.text)
    if match.kind != "new":
        return _left("повтор", job)
    vacancy_id = await _store(kit, job, page, key, match.embedding)
    job.submitted += 1
    job.found.append(vacancy_id)
    queue.put(vacancy_id, page.text)
    return _left("принята", job)


def _left(answer: str, job: SeekJob) -> str:
    return f"{answer}; можно передать ещё {max(job.limit - job.submitted, 0)}"


async def _known(kit: AgentKit, aggregator_id: int, key: str) -> bool:
    """Номер уже видели: вакансия с ним заведена или удалена как мусор."""
    async with kit.pipeline.session_factory() as session:
        stored = await session.scalar(select(Vacancy.id).where(
            Vacancy.source_aggregator_id == aggregator_id, Vacancy.source_key == key
        ).limit(1))
        return stored is not None or await source_trashed(session, aggregator_id, key)
```

```python
from dataclasses import dataclass

from sqlalchemy import func, select
from sqlalchemy.ext.asyncio import AsyncSession

from backend.models import Application, ApplicationVia, Screening
from backend.repository.vacancies_life import add_vacancy_event
from backend.repository.vacancy_status import mark_vacancy_applied
from backend.telegram_time import utc_now

_EXPLANATION = {
    ApplicationVia.AGGREGATOR: "Отклик на сайте агрегатора.",
    ApplicationVia.FORM: "Отклик формой работодателя.",
    ApplicationVia.EMAIL: "Отклик письмом.",
}


@dataclass(frozen=True)
class ApplicationEntry:
    vacancy_id: int
    aggregator_id: int | None
    via: ApplicationVia
    target: str
    letter: str | None
    letter_by: str | None
    screening: list[tuple[bool, str]]
    simulated: bool


async def application_exists(session: AsyncSession, vacancy_id: int, target: str) -> bool:
    return await _existing(session, vacancy_id, target) is not None


async def record_application(session: AsyncSession, entry: ApplicationEntry, *, forced: bool) -> int:
    """Записать состоявшийся отклик. Тот же адрес второй строки не даёт — скрининг дописывается."""
    known = await _existing(session, entry.vacancy_id, entry.target)
    if known is not None:
        await _add_screening(session, known.id, entry.screening)
        return known.id
    row = Application(
        vacancy_id=entry.vacancy_id, aggregator_id=entry.aggregator_id, via=entry.via,
        target=entry.target, letter=entry.letter, sent_at=utc_now(),
    )
    session.add(row)
    await session.flush()
    await _add_screening(session, row.id, entry.screening)
    await mark_vacancy_applied(session, entry.vacancy_id, _EXPLANATION[entry.via], force=forced)
    await add_vacancy_event(session, entry.vacancy_id, "applied_elsewhere", {
        "via": entry.via.value, "target": entry.target,
        "simulated": entry.simulated, "letter_by": entry.letter_by,
    })
    return row.id


async def _existing(session: AsyncSession, vacancy_id: int, target: str) -> Application | None:
    return await session.scalar(select(Application).where(
        Application.vacancy_id == vacancy_id, Application.target == target
    ))


async def _add_screening(session: AsyncSession, application_id: int, lines) -> None:
    start = await session.scalar(
        select(func.count(Screening.id)).where(Screening.application_id == application_id)
    ) or 0
    for offset, (from_us, text) in enumerate(lines):
        session.add(Screening(application_id=application_id, from_us=from_us,
                              text=text, position=start + offset))
```

```python
from sqlalchemy.ext.asyncio import AsyncSession

from backend.llm.external import external_block
from backend.models import Aggregator, TelegramChannel, Vacancy
from backend.repository.vacancy_contacts import list_contacts


async def describe_vacancy(session: AsyncSession, vacancy_id: int) -> str | None:
    """Вакансия текстом для агента. Пусто — вакансии нет.

    Одна сборка на инструмент `vacancy` и на задание откликателя: две подписи
    одного и того же разошлись бы, и агент увидел бы два описания своей

    if vacancy is None:
        return None
    contacts = [c.value for c in await list_contacts(session, vacancy_id)]
    return "\n".join([
        f"Вакансия: {vacancy.title or '—'}",
        f"Компания: {vacancy.company_name or '—'}",
        f"Источник: {await _source(session, vacancy)}",
        f"Адрес страницы вакансии: {vacancy.source_url or '—'}",
        f"Контакты вакансии: {', '.join(contacts) or '—'}",
        "",
        external_block(vacancy.raw_text or "", "текст вакансии со страницы"),
    ])


async def _source(session: AsyncSession, vacancy: Vacancy) -> str:
    if vacancy.source_aggregator_id is not None:
        site = await session.get(Aggregator, vacancy.source_aggregator_id)
        return site.name if site else "—"
    if vacancy.source_channel_id is not None:
        channel = await session.get(TelegramChannel, vacancy.source_channel_id)
        return f"@{channel.username}" if channel else "—"
    return "заведена человеком"
```

```python
_AGGREGATOR, _FORM = ApplicationVia.AGGREGATOR.value, ApplicationVia.FORM.value
_ALLOWED = {_AGGREGATOR: {_AGGREGATOR, _FORM}, _FORM: {_FORM}, ApplicationVia.EMAIL.value: set()}


def applier_tools(kit: AgentKit, job: ApplyJob) -> list[Callable]:
    """Инструменты откликателя, привязанные к своей вакансии и своему способу."""

    async def vacancy() -> str:
        """Своя вакансия: название, компания, источник, адрес страницы, контакты и текст."""
        async with kit.pipeline.session_factory() as session:
            return await describe_vacancy(session, job.vacancy_id) or "Вакансия удалена."

    async def record_application(
        via: str, target: str, letter: str = "", screening: list[dict] | None = None,
        already_applied: bool = False,
    ) -> str:
        """Записать отклик, который сайт подтвердил: aggregator или form, адрес страницы или формы, письмо, вопросы и ответы скрининга по порядку. Повтор с тем же адресом дописывает скрининг."""
        if via not in _ALLOWED[job.method]:
            return "Этим способом отклик не пишется; письмо записывает send_email."
        lines = _lines(screening or [])
        if isinstance(job.outcome, Applied):
            return await _append(kit, job.outcome.application_id, lines)
        entry = _entry(job, _Report(via, target, None if already_applied else (letter or None), lines))
        async with kit.pipeline.session_factory() as session:
            async with session.begin():
                application_id = await store(session, entry, forced=job.forced)
        job.outcome = Applied(application_id)
        kit.pipeline.fire_vacancies_changed()
        return "Отклик записан."

    return [vacancy, record_application]
```

У `record_application` пять параметров — предел четыре, но имена и порядок
задаёт агент, это его подпись. Хук отклонит запись. Тогда параметры
переходят в одну модель: `record_application(entry: ApplicationReport)`, где
`ApplicationReport` — pydantic-модель с теми же полями. FastMCP строит из неё
схему так же. Решение — по ответу хука на первую запись. Если хук пропустит
подпись агента, она остаётся плоской.

`_Report(via, target, letter, screening)` — замороженный датакласс того, что
сообщил агент. `_entry(job, report)` собирает из него `ApplicationEntry`:
`aggregator_id=job.aggregator_id`, `via=ApplicationVia(report.via)`,
`letter_by=job.letter_writer if report.letter else None`, `simulated=job.simulated`.
`_lines(screening)` — `[(bool(x.get("from_us")), str(x.get("text", ""))) for x in screening]`.
`_append(kit, application_id, lines)` дописывает скрининг к отклику, уже
записанному в этой сессии: вопросы со страницы подтверждения ложатся туда
же, даже если её адрес другой. Для этого `_add_screening` в
`repository/applications.py` становится публичной `append_screening`. Тест:
второй `record_application` с другим адресом после записанного отклика
второй строки не заводит, а скрининг дописан. Способ и его адрес инструмент
`vacancy` не повторяет: их агент получает в задании (`applier_task`), а сама
вакансия в задании — тот же текст `describe_vacancy`.

```python
"""MCP-сервер инструментов одной сессии агента: HTTP на 127.0.0.1, токен в адресе."""

import asyncio
import logging
import secrets
import socket
from dataclasses import dataclass
from typing import Callable

import uvicorn
from mcp.server.fastmcp import FastMCP

SERVER_NAME = "jobbot"
_START_SEC = 10
_CLOSE_SEC = 5
logger = logging.getLogger(__name__)


@dataclass
class ToolServer:
    url: str
    _server: uvicorn.Server
    _task: asyncio.Task

    async def close(self) -> None:
        """Закрыть, не дожидаясь висящих вызовов: ждущий человека вызов иначе
        держал бы остановку до часа."""
        self._server.should_exit = True
        self._server.force_exit = True
        try:
            await asyncio.wait_for(self._task, _CLOSE_SEC)
        except TimeoutError:
            self._task.cancel()
            logger.warning("MCP-сервер не закрылся за %s с, погашен", _CLOSE_SEC)


async def serve_tools(tools: list[Callable]) -> ToolServer:
    """Поднять сервер с инструментами сессии на свободном порту.

    Сервер на каждую сессию свой: инструменты замкнуты на её задачу, и
    токен в адресе не даёт чужому процессу на машине позвать их по
    угаданному порту.
    """
    token = secrets.token_urlsafe(24)
    mcp = FastMCP(SERVER_NAME, streamable_http_path=f"/{token}/mcp",
                  stateless_http=True, json_response=True)
    for tool in tools:
        mcp.add_tool(tool, name=tool.__name__, description=tool.__doc__ or "")
    sock = socket.socket()
    sock.bind(("127.0.0.1", 0))
    port = sock.getsockname()[1]
    # log_config=None: в оконной сборке sys.stdout пуст, а журнал uvicorn по
    # умолчанию спрашивает у него isatty. Записи идут в корневой журнал приложения.
    server = uvicorn.Server(uvicorn.Config(mcp.streamable_http_app(), log_config=None))
    task = asyncio.create_task(server.serve(sockets=[sock]))
    await _started(server, task)
    return ToolServer(f"http://127.0.0.1:{port}/{token}/mcp", server, task)


async def _started(server: uvicorn.Server, task: asyncio.Task) -> None:
    deadline = asyncio.get_running_loop().time() + _START_SEC
    while not server.started:
        if task.done():
            task.result()
            raise RuntimeError("MCP-сервер закончил работу, не начав")
        if asyncio.get_running_loop().time() > deadline:
            task.cancel()
            raise TimeoutError("MCP-сервер не поднялся")
        await asyncio.sleep(0.01)
```

Тест закрытия: сервер с инструментом, который ждёт события вечно; вызов
начат; `close()` возвращается за несколько секунд.

```python
"""Сессия агента в своём процессе Claude Code: инструменты приложения, без чужих настроек."""

import json
import logging
import re
from dataclasses import dataclass

from adapters import claude_code, claude_code_process
from adapters.agent_mcp import SERVER_NAME

logger = logging.getLogger(__name__)

_TOOL_TIMEOUT_MS = 65 * 60 * 1000
_LIMIT_STATUS = 429
# Признака «исчерпан лимит подписки» Claude Code не даёт; статус 429 приходит
# не всегда, и тогда остаются слова в тексте беды. Сверяется живым прогоном.
_LIMIT_RE = re.compile(r"usage limit|limit reached|rate limit", re.IGNORECASE)


@dataclass(frozen=True)
class AgentRun:
    system_prompt: str
    task: str
    mcp_url: str
    model: str
    web_search: bool


async def run_agent(run: AgentRun) -> AgentEnd:
    """Одна сессия — один процесс. Процесс закрывается, чем бы сессия ни кончилась."""
    try:
        process = await claude_code_process.spawn_cli(_argv(claude_code.cli(), run), _env())
    except (OSError, claude_code.CliTrouble) as e:
        logger.exception("агент не запустился")
        return AgentEnd(False, f"агент не запустился: {e}", False)
    try:
        await claude_code_process.send_line(process, run.task)
        return _end(await claude_code_process.read_result(process))
    except (claude_code_process.ProcessGone, OSError) as e:
        logger.exception("процесс агента оборвался")
        return AgentEnd(False, f"процесс агента оборвался: {e}", False)
    finally:
        if process.returncode is None:
            process.kill()


def _end(data: dict) -> AgentEnd:
    """Итог сессии по итогу процесса; беду разбирает тот же `reply_of`, что у чата."""
    try:
        text, _finish = claude_code.reply_of(data)
    except claude_code.CliTrouble as trouble:
        detail = str(trouble)
        limit = trouble.status == _LIMIT_STATUS or bool(_LIMIT_RE.search(detail))
        return AgentEnd(False, detail, limit)
    return AgentEnd(True, text or "", False)


def _argv(cli: str, run: AgentRun) -> list[str]:
    """Доводы чата плюс инструменты приложения.

    `--allowedTools` обязателен: без него каждый вызов инструмента ждал бы
    разрешения, а в режиме `-p` дать его некому.
    """
    builtins = "WebSearch" if run.web_search else ""
    allowed = f"mcp__{SERVER_NAME}" + (",WebSearch" if run.web_search else "")
    config = json.dumps({"mcpServers": {SERVER_NAME: {"type": "http", "url": run.mcp_url}}})
    return [
        *claude_code_process.stream_argv(cli, run.model, run.system_prompt, builtins),
        "--allowedTools", allowed, "--mcp-config", config,
    ]


def _env() -> dict:
    """Окружение подписки и срок вызова инструмента дольше часа ожидания человека."""
    return {**claude_code_process.subscription_env(), "MCP_TOOL_TIMEOUT": str(_TOOL_TIMEOUT_MS)}
```

```python
from adapters.claude_code_agent import AgentEnd, AgentRun, run_agent

SESSION_LIMIT_SEC = 3 * 3600


class HumanTimeout(Exception):
    """Человек не справился с капчей или входом за час — обход снимается."""


class LimitExhausted(Exception):
    """Исчерпан лимит подписки водителя — следующий источник упёрся бы в то же."""


async def run_guarded(kit: AgentKit, plan: SessionPlan) -> AgentEnd:
    """Сессия наперегонки со сроками. Отмена снаружи гасит сессию и ждёт её конца."""
    session = asyncio.create_task(kit.run_session(plan))
    expiry = asyncio.create_task(kit.gate.expired.wait())
    try:
        done, _ = await asyncio.wait(
            {session, expiry}, timeout=SESSION_LIMIT_SEC, return_when=asyncio.FIRST_COMPLETED
        )
    except asyncio.CancelledError:
        await put_out(session)
        raise
    finally:
        expiry.cancel()
    if session in done:
        return session.result()
    await put_out(session)
    if expiry in done:
        raise HumanTimeout
    return AgentEnd(False, "сессия агента превысила срок", False)


def live_session(model: str) -> RunSession:
    async def run(plan: SessionPlan) -> AgentEnd:
        server = await serve_tools(plan.tools)
        try:
            return await run_agent(AgentRun(plan.system_prompt, plan.task, server.url,
                                            model, plan.web_search))
        finally:
            await server.close()
    return run
```

```python
def _occupy(bot, label: str) -> bool:
    """Занять место прогона; занято — отказ с записью в журнал."""
    if bot.current_poll_task is not None:
        logger.info("%s: another cycle is already running, skipping", label)
        return False
    fire(bot.on_cycle_start, "on_cycle_start")
    return True


def _release(bot) -> None:
    """Освободить место и сказать окну, что прогон кончился."""
    bot.current_poll_task = None
    fire(bot.on_cycle_end, "on_cycle_end")


async def run_in_slot(
    bot,
    work: Callable[[], Any],
    label: str,
    progress: tuple[str, str, int, int] | None = None,
) -> tuple[CycleOutcome, Any]:
    if not _occupy(bot, label):
        return "busy", None
    if progress is not None:
        fire(bot.on_progress, "on_progress", *progress)
    try:
        outcome, result = await _run_task(bot, work, label)
    finally:
        _release(bot)
    return outcome, result


def launch_in_slot(bot, work: Callable[[], Any], label: str) -> bool:
    """Занять место прогона отдельной задачей и вернуться сразу.

    Обход агрегаторов ждёт человека до часа. Цикл бота при этом должен
    тикать: таймер Ghosting, смена режима, проверка остановки.

    Обёртка записывается в `current_poll_task` сразу — место занято с первого
    мгновения; первым шагом `_run_task` подменяет её задачей работы, и «Стоп»
    гасит уже её. Освобождает место конец обёртки, а не `finally` в ней:
    погашенная до первого шага задача не исполнит ни строки.
    """
    if not _occupy(bot, label):
        return False
    task = asyncio.create_task(_run_task(bot, work, label))
    bot.current_poll_task = task
    task.add_done_callback(lambda _done: _release(bot))
    return True
```

Журнал беды и «cancelled by user» пишет `_run_task` — для обоих входов
одними словами.
