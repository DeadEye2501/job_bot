## Как работать

- Скилл `free-hands:keeping-code-clean`. Манифест
  (`C:\Users\deade\.claude\skills\free-hands\skills\keeping-code-clean\MANIFEST.md`)
  перечитывать **целиком** перед первой правкой каждой задачи — не первые
  строки ради хука, а все шестнадцать правил, и сверять с ними задуманное.
- Готовое искать **по картам** (`docs/maps/module-map.md`, `data-map.md`,
  `front-map.md`), по делу, а не по имени. Карты пересобирать после правок:
  `pipenv run python "C:/Users/deade/.claude/skills/free-hands/skills/keeping-code-clean/tools/module_map.py"`
  и `.../tools/front_map.py`.
- Тест — до кода, хоть раз красный. Правки в поведении без теста не делаются.
- Фронт: `npm test --prefix client/web`, сборка `npm run build --prefix client/web`.
  Питон: `pipenv run python -m pytest tests -q -p no:cacheprovider` (около 3 минут).
- После правки экрана — пересобрать фронт и сразу запустить приложение
  (`pipenv run python main.py`, в фоне), не спрашивая.
- Ревью — агентами по `superpowers:requesting-code-review`, коммит — после
  ревью. «Коммит» = `git add .` и коммит всего дерева.
- Мутаций нет: человек их отменил.
- Рецензент по манифесту бэкенда на всём диапазоне трижды падал на фильтре
  сервиса (`reasoning_extraction`), на Opus и на Sonnet; разбитый на три части
  (`backend`+`adapters`, `client/bridge`, `tests`) — прошёл. Большой объём
  резать на части сразу.

## 1. Ошибки поведения

- [ ] **Почта: при смене адреса остаётся сервер прежней почты** (найдено тремя
  рецензентами независимо — главное в ревью).
  - Где: `client/web/app/SettingsScreen.svelte:124-133` (`saveMail`),
    `backend/repository/mail_account.py:84-88` (`_server`),
    `client/bridge/mail.py:23-31`.
  - Что: окно шлёт почту целиком `{...mail, ...part}` с прежним `smtp_host`,
    который мост сам подставил по домену. `_server` при непустом host берёт его
    как набранный руками. Gmail → Яндекс: в базе остаётся `smtp.gmail.com`,
    `server_by_address` для нового адреса `true` — поля сервера скрыты, плашка
    «подключена», письмо не уходит, поправить из окна нельзя.
  - Как: в `_server` — если `known_server(address)` не пусто, брать его и не
    смотреть на присланный host (совпадает с тем, что окно показывает по
    `server_by_address`). Дополнительно можно в `saveMail` слать
    `smtp_host`/`smtp_port` только когда видны поля сервера
    (`mailNeedsServer(next)`). Тест: смена адреса с одной популярной почты на
    другую даёт сервер новой.

- [ ] **Контакты вакансии из запоздалого ответа ложатся на другую вакансию.**
  - Где: `client/web/app/VacancyContactsSection.svelte:17,24-27`.
  - Что: ответ `vacancies.add_contact` / `delete_contact` отдаётся в
    `onchanged` без сверки номера; карточка одна на весь список. Нажал × у
    вакансии A, сразу выбрал B — под B встают контакты A.
  - Как: сверять `done.vacancy_id === vacancyId` перед `onchanged` в обоих
    местах (мост номер возвращает). Так уже защищены `respond` и
    `showScreening` в `VacancyCard.svelte`.

- [ ] **`httpx.InvalidURL` не ловится при заведении агрегатора.**
  - Где: `adapters/site_home.py:235-238` (`fetch_icon`),
    `backend/flows/aggregator_name.py:287-295` (`_site`).
  - Что: `InvalidURL` не наследуется от `httpx.HTTPError`. Кривая ссылка на
    значок в шапке сайта или адрес с пробелом — агрегатор не заводится, окно
    получает общую ошибку.
  - Как: ловить `(httpx.HTTPError, httpx.InvalidURL)` в обоих местах.

- [ ] **Почтовые контакты сверяются с отсевом как ссылки.**
  - Где: `backend/repository/aggregators.py:110-123` (`vacancy_barred_host`),
    `backend/domain/hosts.py` (`owning_host`).
  - Что: при отсеве `hh.ru` контакт `jobs@career.hh.ru` отсеивается, а
    `jobs@hh.ru` нет — решает написание.
  - Как: сверять с отсевом только ссылки (`is_link`), как уже делает
    `vacancy_ways`.

- [ ] **Пустой список агрегаторов без поиска** — подпись «Ничего не найдено по
  запросу «»».
  - Где: `client/web/app/AggregatorsList.svelte:87-89`.
  - Как: ветка `{#if list.search} … {:else} …` как у каналов. (Сводится заодно
    с дублем фронта № 5 — общая вкладка источников.)

- [ ] **(На решение)** Под симуляцией отклика обрывается любой POST, включая
