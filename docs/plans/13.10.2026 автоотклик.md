# План: автоотклик

**Цель:** тумблер «Автоотклик» решает, передаётся ли разобранное откликателю;
симуляция отправки уходит из интерфейса.

**Устройство:** новая строка настроек `auto_apply` (умолчание — включён).
Передача откликателю (`backend/flows/handover.py`, `hand_over`) при выключенном
автоотклике не зовёт `pipeline.apply` — это единственное место решения, и через
него идут прогон, «Прогнать заново» и разбор вставленного объявления. Догон
нового HR после разбора остаётся как есть: это не откликатель. Мост пишет и
отдаёт `auto_apply` вместо `send_locked`; окно показывает тумблер на месте
симуляции.

**Спека:** `docs/specs/13.10.2026 автоотклик.md`.

**Порядок работы:** слайс за слайсом — тесты до кода и красными, код, весь набор
зелёным, карты, ревью отдельными агентами, правки, коммит. После всех слайсов —
полное ревью. Мутаций нет нигде, в полном ревью тоже.

Тесты питона: `pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.

## Общие условия

- Ручной отклик («Откликнуться» в карточке, «!») зовёт откликатель мимо передачи
  и не трогается.
- Код режима симуляции (`send_locked` в `runtime_settings`, откликатель,
  `telegram.SEND_LOCKED`) остаётся как есть.
- Тексты окна — на «вы», без жаргона; у тумблера подсказки по наведению нет.

## Что проверить в ревью

- Автоотклик выключен, а разбор завёл нового HR — догон его переписки идёт, как
  и при включённом.
- Автоотклик выключили посреди прогона — вакансии, разобранные после записи,
  откликателю не уходят (настройка читается на каждой передаче, не при старте).
- Старое окно или стенд шлёт `send_locked` в сохранение — в базу не пишется.
- Пустая база — тумблер стоит включённым, прогон откликается, как раньше.

```python
async def test_with_auto_apply_off_a_fit_vacancy_stays_in_new(parsing, session_factory):
    """Выключенный автоотклик — после разбора откликатель не зовётся вовсе."""

    await pipeline.rs.set_app("auto_apply", "false")

    assert pipeline.applied == []
    async with session_factory() as session:
        assert (await session.get(Vacancy, vacancy.id)).status == VacancyStatus.NEW


async def test_with_auto_apply_off_a_new_hr_is_still_caught_up(parsing, monkeypatch):
    """Догон переписки — не откликатель, автоотклик его не касается."""
    pipeline, vacancy = parsing
    pipeline.parsed = parsed_vacancy(
        title="Python-разработчик", stack_required=["Python"], hr_contact="@maria")
    await pipeline.rs.set_app("auto_apply", "false")
    caught = []
    monkeypatch.setattr(handover, "spawn_hr_backfill", lambda _p, hr: caught.append(hr))
    await judge_and_hand_over(pipeline, vacancy.id, "Python", "chan")
    assert pipeline.applied == [] and len(caught) == 1
```
