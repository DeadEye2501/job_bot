# План: общий конвейер для всех источников

**Цель:** всякая находка идёт по конвейеру по одной до отклика включительно;
вставленный текст дочитывает статьи Telegraph; заведённая человеком вакансия
всегда в New и уходит откликателю только по переключателю «Отклик при
создании»; однозначный повтор по собственному адресу не заводится; третья
вкладка «Ссылка».

**Устройство:** общие хосты Telegram и Telegraph и единственное распознавание
статьи — в `domain/telegram_identity.py`; таблица площадок и ключ адреса
вакансии — в `domain/hosts.py`. Признак «заведено человеком» — событие
`HAND_MADE` в ленте строки; разбор читает его один раз в начале и не выносит
приговора. Сборка «разбор → передача» одна — `judge_and_hand_over` с объектом
`Intake` (кто завёл, отдавать ли, канал, можно ли сносить); у ручного она же
между разбором и передачей шлёт окну весть одной функцией `tell`. Заявка окна
доходит до бота, бот один раз решает род вкладки, `flows/hand_made.py` ведёт
заявку по пути. Искатель зовёт цикл находки прямо из `submit_vacancy`; очередь
разбора удаляется; срок сессии искателя стоит на паузе, пока идёт вложенный
цикл или ждут человека.

**Спека:** `docs/specs/20.10.2026 Общий конвейер для всех источников.md`.

**Порядок работы:** слайс за слайсом без пауз — поиск готового по картам до
первой строки, тесты до кода и красными, код, весь набор зелёным, ревью тремя
агентами (ошибки, манифест, дубли), правки, коммит. Карты собираются из кода.
Окно проверяю сам после слайсов 6 и 10, пункт «показ» остаётся открытым.
После всех слайсов — полное ревью. Мутаций нет.

Тесты питона: `pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.

- Миграции нет: признак — событие ленты, ключ адреса считается на лету по

## Мои решения при плане

Отмечены здесь, на согласие не выносятся.

- **Фраза повтора** — «Такая вакансия уже существует», ключ `duplicate`
  прежний, плашка не красная (слайс 5).
- **Запор** — фраза `blockedTip` (`state/health.js:49`) нейтральна для всех
  мест: «Нужны все системы, сейчас недоступно: …» (слайс 6).
- **Без Claude Code** — `NO_DRIVER` (`agent/availability.py:6`): «Нужен Claude
  Code: выберите его поставщиком чата» (слайс 10).
- **Переход при скрывающем отборе** — `goVacancy` открывает карточку по номеру,
  отбор не сбрасывается (`repository/vacancies_card.py:57-75` грузит без
  отбора); человек в другом разделе — раздел переключается.
- **`RowToggle`** держит положение по ответу зова; зов переключателя явно
  отдаёт `true`.
- **Пост по ссылке и канал** — связь по `msg.chat.username` прочитанного
  поста через `find_channel_by_username`; у закрытого канала ника нет —
  `source_channel_id` пуст, источник — вставленный адрес (у `TelegramChannel`
  нет id Telegram).
- **Фразы бед Telegram** — общие для окна канала и ручного заведения, без ника
  в тексте; у окна канала появляется фраза закрытого канала.
- **`?gh_jid=`** на чужом хосте — ключ «хост + номер»; совпадение двух разных
  сайтов исключено.
- **Лента** — `HAND_MADE` у поста и страницы несёт нагрузку `"ingested"` /
  `"found"`, история показывает источник у «заведено вручную».
- **Знакомая строка** у ручного удаляется (`pasted._finish_or_refuse` вместе с
  веткой `known_or_new`); сводятся два близнеца автоматики —
  `ingest._resume_or_skip` и ветка `_submit` (слайс 8).
- **Срок вызова инструмента** снимается только искателю — ключом `"timeout"`
  его сервера в `--mcp-config`: `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT` общий для
  процесса, а ключ сервера — только его.
- **«Стоп» после вести** заведения, посреди отклика — плашка «остановлено»
  по прежнему пути; ожидание окна уже закрыто.

## Что проверить в ревью

- Ссылка с метками прихода, поддоменом, `http`, косой в конце — тот же ключ;
  адрес без номера и сайт компании — проверки нет, вакансия заводится.
- «Стоп» посреди вложенного отклика и посреди ожидания подтверждения: гаснут
  и отклик, и поиск, сессия отклика кончилась до возврата, записанное цело.
- Весть пришла, когда окно закрыто или человек в другом разделе: черновик
  сброшен или цел по исходу; открыл окно до вести — введённое на месте,
  «Создать» заперта.
- Лампочка погасла, пока ждётся весть: переключатель заперт и показан
  выключенным, загорелась — вернулось запомненное.
- Заведённая вручную при пустом разборе, обрыве, отказе модели, метке мусора
  — New, не снесена; подбор недоразобранного её не передаёт.
