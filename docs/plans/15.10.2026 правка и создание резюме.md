# План: правка и создание резюме

**Цель:** «Перезаписать» правит только выбранное резюме, «Создать новое
резюме» только заводит новое; флаг «сайт даёт завести ещё одно» ставит агент
по списку резюме на сайте. Попутно — короткие подписи под полосами прогресса и
правило «страница не сохраняется» в наставлении заполнения.

**Устройство:** перечень снимает у каждого резюме вторую ссылку — редактор
этого резюме — и флаг `many_resumes` от агента. Заполнение начинается с
редактора выбранного резюме. Ввод держит единственная дверь — `submit_layout`:
раскладка на странице не того резюме отбивается кодом. После работы список
резюме до и после сверяется, и сверка решает успех или ошибку.

**Спека:** `docs/specs/15.10.2026 правка и создание резюме.md`; правит
`docs/specs/14.10.2026 резюме на агрегаторах.md` и
`docs/specs/14.10.2026 автозаполнение резюме.md`.

**Порядок работы:** слайс за слайсом — тесты до кода и красными, код, весь
набор зелёным, карты, ревью отдельными агентами (ошибки, манифест, дубликаты,
тесты), правки, коммит. После всех слайсов — полное ревью. Мутаций нет.

Тесты питона: `pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.

## Общие условия

- Миграций нет: колонка `aggregator_resume.editor_url` уже заведена — цепочка
  миграций сведена в одну `init` (`032b8b1c9f8a`) вместе с ней, модель
  `AggregatorResume.editor_url` есть.
- Наставления — без примет какого-либо сайта: ни GeekJob, ни адресов, ни
  названий его полей.
- Тексты окна — на «вы», без точки на конце, без жаргона.
- Удалять резюме с сайта бот не умеет и не учится.

## Что проверить в ревью

- Перезапись, а агент оказался на странице создания нового резюме: раскладка
  там отбита, на страницу ничего не вписано.
- Создание, а агент открыл редактор существующего резюме: раскладка отбита.
- После перезаписи резюме стало больше: ошибка «Вместо правки заведено новое
  резюме — удалите его на сайте», отметка не ставится.
- После создания новых нет или больше одного: ошибка, отметка не ставится.
- Резюме без адреса редактора (перечень старый или редактор не нашёлся):
  перезапись не запускается, ошибка с просьбой обновить перечень.

## Слайс 2. Заполнение: старт с редактора и дверь ввода

**Файлы:**
- Изменить: `backend/agent/jobs.py` — `FillJob(source, editor_url: str | None,
  other_editors: frozenset[str], ...)`: `editor_url` — редактор
  перезаписываемого резюме, пусто — создание; `other_editors` — редакторы
  всех прочих резюме сайта (у перезаписи — кроме выбранного, у создания —
  все). `resume_url` уходит: задача узнаёт резюме по редактору.
- Изменить: `backend/agent/tools_fill.py` — `submit_layout` первой строкой
  решает, открыто ли нужное резюме: `_off_target(job, url)` — у перезаписи
  адрес страницы не начинается с `editor_url`; у обоих режимов адрес
  начинается с одного из `other_editors`. «Начинается» — тот же адрес или он же
  с продолжением после `/`, `?`, `&`, `#`. Не то резюме — отказ агенту текстом
  «это страница другого резюме — открой редактор резюме из задания» (у
  создания — «… — открой создание нового резюме»), в `job.accepted` ничего не
  ложится, строка в журнал.
- Изменить: `backend/agent/tools_fill.py` — инструмент `report_no_new_resume
  (reason)`: итог `Finished("no_new_resume", reason)`; выдаётся только задаче
  создания.
- Изменить: `backend/agent/prompts/fill.py` — `fill_task(host, editor_url,
  language)`: у перезаписи — «Открой редактор резюме по адресу …; правь только
  это резюме: новое не заводи, другие не открывай»; у создания — «Заведи новое
  резюме; существующие не открывай для правки; сайт не даёт завести ещё одно —
  report_no_new_resume с причиной, ничего не заполняя». В `FILL_PROMPT` пункт 5
  — правило спеки «Страница не сохраняется»: пройти страницу заново, найти
  пустые обязательные поля, в том числе открывшиеся выбором в другом списке.
- Изменить: `backend/flows/resume_fill.py` — `fill(kit, source, resume_id)`:
  у перезаписи резюме без `editor_url` — `no_editor` до агента; итог
  `no_new_resume` — флаг агрегатора «нельзя» (`kit.written`, `can_add_resume =
  False`), ответ `no_new_resume`, перечня нет.
- Изменить: `backend/bot/aggregators.py` — `AgentOutcome` знает `no_editor`,
  `no_new_resume`; `client/bridge/refusals.py` — `FILL_REFUSALS`: `no_editor`
  — «Не найден редактор резюме — обновите список резюме», `no_new_resume` —
  «Сайт не даёт завести ещё одно резюме».
- Тесты: `tests/backend/test_agent_tools_fill.py`,
  `tests/backend/test_flows_resume_fill.py`,
  `tests/client/test_bridge_aggregators.py`.

**Даёт:** `FillJob.editor_url`, `FillJob.other_editors`; `_off_target`;
