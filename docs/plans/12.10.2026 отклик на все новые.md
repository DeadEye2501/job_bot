# План: отклик на все новые вакансии

**Цель:** значок «!» в нижней полосе откликается подряд на все разобранные
вакансии в New тем же откликателем, что у автоматики.

**Устройство:** бот получает действие `apply_all_new`, которое в месте прогона
берёт список новых и отдаёт его `run.apply_vacancies`. Мост выставляет два
зова: число новых и сам прогон. Нижняя полоса держит число и рисует значок.

**Спека:** `docs/specs/12.10.2026 отклик на все новые.md`.

**Порядок работы:** слайс за слайсом — тесты до кода и красными, код, весь набор
зелёным, карты, ревью отдельными агентами, правки, коммит. После всех
слайсов — полное ревью. Мутаций нет нигде, в полном ревью тоже.

Тесты питона гоняются питоном из pipenv:
`pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.

## Общие условия

- Берутся вакансии в New и разобранные (`PARSED_ONLY` из
  `backend/repository/vacancies_common.py`), от свежих к старым по
  `Vacancy.created_at`.
- Прогон занимает место прогона; режим бота ему не помеха.
- Окна подтверждения нет.
- Тексты окна — на «вы», без жаргона.

## Что проверить в ревью

- Пока идёт прогон, вакансия из списка ушла в другой статус руками — откликатель
  её не трогает (`ways_in` читает факты на месте; убедиться, что отклик
  не уходит на вакансию, которую человек уже убрал из New).
- Прогон остановлен «Стопом» — оставшиеся вакансии стоят в New, число на значке
  пересчитано.
- Новых нет, но нажатие всё же дошло до моста (гонка с перечитыванием числа) —
  прогон с пустым списком кончается спокойно, без ошибки окну.
- Число на значке после прогона, где часть вакансий осталась без способа, — не
  ноль, значок по-прежнему жёлтый.
- Здоровье системы не в порядке — значок заперт с той же подсказкой, что кнопка
  запуска.

async def new_to_apply(session: AsyncSession) -> list[int]:
    """Вакансии, на которые откликается «отклик на все новые»: New и разобранные, свежие первыми."""
    return list(await session.scalars(
        select(Vacancy.id)
        .where(Vacancy.status == VacancyStatus.NEW, PARSED_ONLY)
        .order_by(Vacancy.created_at.desc(), Vacancy.id.desc())
    ))
```

ApplyAllOutcome = Literal[slot.CycleOutcome, work.AgentStop]
"""Чем кончился отклик на все новые: исходы места прогона и работы с агентом."""


async def apply_all_new(bot) -> ApplyAllOutcome:
    """Откликнуться подряд на все новые разобранные вакансии. Режим не помеха: нажал человек.

    Список берётся уже в месте прогона: взятый до него разошёлся бы с тем, что
    успел сделать прогон, ждавший места.
    """

    async def apply(kit: AgentKit) -> str:
        await bot.ingestion.reload_resources()
        async with bot.session_factory() as session:
            vacancy_ids = await new_to_apply(session)
        await run.apply_vacancies(kit, vacancy_ids)
        return "ok"

    return await work.in_slot(bot, apply, "apply all new")
```

    def new_vacancies(self) -> dict:
        """Сколько вакансий возьмёт «отклик на все новые»."""

        async def run() -> dict:
            async with self._hub.session_factory() as session:
                counts = await count_by_status(session, PARSED_ONLY)
            return {"count": counts[VacancyStatus.NEW]}

        return reply(self._hub.runner, run())

    def apply_all_new(self) -> dict:
        """Откликнуться подряд на все новые вакансии."""
        bot = self._hub.bot
        if bot is None:
            return denied(NO_BOT, action="apply_all_new")
        return launched(self._hub, bot.apply_all_new, APPLY_ALL_REFUSALS,
                        "Отклики на новые вакансии закончены.", action="apply_all_new")
