# План: портфолио

**Цель:** четвёртая вкладка профиля Projects — проекты, которые человек
показывает помимо мест работы; они разбираются из резюме и участвуют в
откликах так же, как места работы.

**Устройство:** проект — место работы без должности, без дат и с одним
перечнем «О проекте». Всё, что у мест работы общее с проектами, выносится из
кода мест работы в общее и работает для обоих: запись перечня целиком со
стеком, снятие связок при удалении навыка, разбор и проверка стека из резюме,
карточка и вкладка окна. Новое пишется только там, где проект отличается:
поля, обязательное поле, порядок, заголовок раздела в анкетах, стаж.

**Спека:** `docs/specs/13.10.2026 портфолио.md`.

**Порядок работы:** слайс за слайсом — тесты до кода и красными, код, весь набор
зелёным, карты, ревью отдельными агентами, правки, коммит. После всех слайсов —
полное ревью. Мутаций нет нигде, в полном ревью тоже. Экран показывается
человеку после слайса 2; ревью фронта — общим, в конце.

Тесты питона: `pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.
Карты: `module_map.py` и `front_map.py` из `tools/` скилла keeping-code-clean,
обе с `--check` после сборки.

## Общие условия

- Поведение мест работы не меняется: те же поля, тот же порядок (от свежих к
  давним при загрузке), те же отказы. Существующие тесты мест работы — сторож
  выноса общего: правятся в них только имена вынесенного.
- Проект: `name` (обязательно), `url`, `about` (перечень строк), стек — связка
  с навыками анкеты, как у места работы.
- Порядок проектов — порядок записи: окно шлёт перечень в показанном порядке,
  запись кладёт строки по порядку, список отдаётся по номеру строки.
- Стаж, общий и по навыку, считается только по местам работы.
- Тексты окна — на «вы», без жаргона. Подписи: вкладка «Projects», поля
  «Название проекта», «Ссылка», перечень «О проекте», «Стек», кнопка
  «+ Добавить проект».
- Примеры в промптах — заглушки, не из резюме человека и не из одного ремесла.

## Что проверить в ревью

- Удаление навыка, привязанного к проекту, на вкладке Skills не падает на
  внешнем ключе и снимает навык со стека проекта, как с места работы
  (тест — слайс 1).
- Повторный разбор резюме стирает прежние проекты вместе с их связками, а не
  дописывает новые к старым (тест — слайс 3).
- Резюме без раздела проектов — проектов нет, места работы разбираются как
  прежде; резюме, где проекты стоят раньше мест работы, — стек мест работы не
  теряется (тест — слайс 3).
- Свежий пустой проект не отменяет записи соседних; записанный проект с
  опустошённым названием называется номером, а не стирается молча
  (тест — слайс 2).
- Навык только из проектов — в анкете агента без срока, но как имеющийся
  (тест — слайс 4).

Запись перечня у проектов та же, что у мест работы, и сторожится там; здесь —
разница проекта: одно обязательное поле, перечень «О проекте», порядок без дат.

from backend.repository.profile_records import RowError

async def _person(session_factory):
    person = profile_row()
    await put(session_factory, person)
    return person


async def test_projects_come_back_in_the_order_they_were_sent(session, session_factory):
    """Дат у проекта нет: порядок — тот, в каком человек их расставил."""
    person = await _person(session_factory)

    await save_projects(session, [{"name": "Свежий"}, {"name": "Давний"}], person.id)

    assert [p.name for p in await list_projects(session)] == ["Свежий", "Давний"]


async def test_a_nameless_project_is_refused_by_its_number(session, session_factory):
    """Название — единственное обязательное поле; без него не пишется ничего."""
    person = await _person(session_factory)

    with pytest.raises(RowError) as refused:
        await save_projects(session, [{"name": "Бот"}, {"name": "  "}], person.id)

    assert refused.value.index == 2
    assert await list_projects(session) == []


async def test_a_project_keeps_its_link_points_and_stack(session, session_factory):
    person = await _person(session_factory)
    await put(session_factory, profile_skill_row(person.id, "Python"))

    await save_projects(session, [{
        "name": "Бот", "url": " https://example.org/bot ",
        "about": ["Описание", " Пункт "], "skill_names": ["python"],
    }], person.id)

    [project] = await list_projects(session)
    assert (project.url, project.about) == ("https://example.org/bot", ["Описание", "Пункт"])
    assert [s.name for s in project.skills] == ["Python"]
