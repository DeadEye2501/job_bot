# План: автозаполнение резюме

**Цель:** кнопки «Перезаписать» (строка резюме) и «Создать новое резюме»
(справа от входа) заполняют резюме на сайте агрегатора по профилю приложения,
каждое поле — в самое подходящее место.

**Устройство:** новая задача агента `FillJob` и своя роль. На каждой странице
код снимает опись полей (новая функция в `page_fields`), агент отдаёт раскладку
страницы одним инструментом, пункты запасного пути с обоснованиями уходят
проверяющему — одним вызовом модели чата на страницу, по образцу проверки
писем. Вписать можно только принятое: строгий ввод отклика с подтверждением
обобщается со «подтверждённого человеком» на «принятое». После заполнения —
сканирование и отметка заполненного резюме.

**Спека:** `docs/specs/14.10.2026 автозаполнение резюме.md`; опирается на
`docs/specs/14.10.2026 новые поля профиля.md` и
`docs/specs/14.10.2026 резюме на агрегаторах.md` — их планы выполняются раньше.

**Порядок работы:** слайс за слайсом — тесты до кода и красными, код, весь набор
зелёным, карты, ревью отдельными агентами (ошибки, манифест, дубликаты, тесты),
правки, коммит. Окно показывается человеку после слайса 4. После всех слайсов —
полное ревью. Мутаций нет.

Тесты питона: `pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.

## Общие условия

- Миграций нет: всё нужное заведено общей миграцией плана «новые поля
  профиля».
- Без подтверждений человека и без оглядки на симуляцию отправки: браузер
  открывается с `sending=True`.
- Действие человека: работает в любом режиме бота, занимает место прогона.
- Проверяющий — модель чата (`pipeline.lm_client`, `lm_chat_model`), не сессия
  агента. Сбой вызова — запасной путь разрешён, строка в журнал.
- Две проверки на страницу; страница — адрес. Сменилась страница — счётчик
  свой.
- Галочку согласия на ПД, без которой форма не сохраняется, агент ставит сам;
  оферты, платное, подписки — нет.
- Тексты окна — на «вы», без жаргона.

## Что проверить в ревью

- Агент пытается вписать в поле «О себе» текст, которого нет в принятой
  раскладке, — отказ, на страницу не попадает.
- Проверяющий отбил пункт дважды — третьей проверки нет, пункт не вписан в
  общее поле, в журнале строка.
- Модель чата недоступна — заполнение идёт, запасной путь разрешён, в журнале
  строка о сбое проверки.
- Обязательное поле без данных — заполнение остановлено, плашка «Не хватает
  данных для обязательных полей», в журнале — каких полей.
- «Стоп» посреди заполнения — браузер закрыт, место прогона свободно, резюме
  не отмечено.
