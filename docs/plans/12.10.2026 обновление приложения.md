# План: обновление приложения из релизов GitHub

**Цель:** собранный `JobBot.exe` узнаёт о новой версии на GitHub, по нажатию
скачивает её и заменяет себя через копию в режиме `--update`.

**Устройство:** номер версии — константа в коде; адаптер читает последний релиз
GitHub и качает файл потоком. Скачивание занимает место прогона и шлёт ход
стадией `update`. После проверенной загрузки мост запускает копию exe с
`--update` и закрывает окно штатно; копия ждёт выхода, подменяет exe и
запускает новый.

**Спека:** `docs/specs/12.10.2026 обновление приложения.md`.

**Порядок работы:** слайс за слайсом — тесты до кода и красными, код, весь набор
зелёным, карты, ревью отдельными агентами, правки, коммит. После всех
слайсов — полное ревью. Мутаций нет нигде, в полном ревью тоже. Начинается после плана
«отклик на все новые»: значок обновления встаёт левее значка «!».

Тесты питона: `pipenv run python -m pytest <файлы> -q -p no:cacheprovider`.
Тесты фронта: `cd client/web && npx vitest run <файл>`.

## Общие условия

- Репозиторий: `DeadEye2501/job_bot`; адрес проверки
  `https://api.github.com/repos/DeadEye2501/job_bot/releases/latest`.
- Версия вида `1.0.0`, показ `v1.0.0`, тег релиза `v1.0.0`, файл релиза
  `JobBot.exe`.
- Проверка — при запуске (беда молчит) и по нажатию (ответ плашкой цветом
  сообщения). Периодической нет.
- Обновляться может только собранный exe (`sys.frozen`); из исходников значка нет,
  номер версии в боковом меню есть.
- HTTP в тестах — `httpx.MockTransport` через подменяемую `make_client`, как в
  `tests/fakes/site_home.py`.

## Что проверить в ревью

- Связь оборвалась посреди скачивания — недокачанный файл удалён, приложение
  работает, плашка говорит причину.
- Скачанный файл не сошёлся по размеру или контрольной сумме — то же.
- «Стоп» во время скачивания — файл удалён, место прогона свободно.
- У релиза нет файла `JobBot.exe` или тег не разбирается как версия — проверка
  отвечает «новой версии нет», а не падает.
- Подмена: exe занят дольше обычного (антивирус держит файл) — копия ждёт с
  повторами, а не бросает старый exe переименованным.

```python
"""Версия приложения: единственное место, где оно знает свой номер."""

VERSION = "1.0.0"


def parse_version(text: str) -> tuple[int, int, int] | None:
    """Номер из тега вида `v1.2.3`; не номер — пусто."""
    parts = text.removeprefix("v").split(".")
    if len(parts) != 3 or not all(part.isdigit() for part in parts):
        return None
    return int(parts[0]), int(parts[1]), int(parts[2])


def is_newer(tag: str) -> bool:
    """Новее ли релиз с этим тегом, чем запущенное приложение."""
    found = parse_version(tag)
    return found is not None and found > parse_version(VERSION)
```

- [x] **Тесты адаптера** (`MockTransport`, маршрут `GET /repos/DeadEye2501/job_bot/releases/latest`):

  `digest: "sha256:…"`) → `Release`; релиз без `JobBot.exe` → пусто; ответ

- [x] Красные. **Код:** (по ревью: 404 — «релизов нет» → пусто; файл без контрольной

```python
"""Последний релиз приложения на GitHub."""

from dataclasses import dataclass

import httpx

from adapters.web_page import page_client

LATEST = "https://api.github.com/repos/DeadEye2501/job_bot/releases/latest"
ASSET = "JobBot.exe"
_TIMEOUT_SEC = 20.0
_USER_AGENT = "JobBot-updater"


@dataclass(frozen=True)
class Release:
    tag: str
    url: str
    size: int
    sha256: str


def make_client() -> httpx.AsyncClient:
    return page_client(_TIMEOUT_SEC, _USER_AGENT)


async def latest_release() -> Release | None:
    """Последний релиз с файлом приложения; релиз без него — пусто."""
    async with make_client() as client:
        response = await client.get(LATEST)
        response.raise_for_status()
    body = response.json()
    asset = next((a for a in body.get("assets", []) if a.get("name") == ASSET), None)
    if asset is None:
        return None
    return Release(body["tag_name"], asset["browser_download_url"], asset["size"],
                   asset.get("digest", "").removeprefix("sha256:"))
```
